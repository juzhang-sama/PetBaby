## 关键技术结论

1. **gpt-image-2 输出不透明 RGB**（无 alpha 通道）→ 桌宠资产必须走后处理去背景；均匀背景（浅灰）色键方案可靠，混合背景需 rembg（待实测）。
2. **身份保持依赖提示词 + 参考图**：参考图特征保持效果需真实宠物照片确认（合成样本上毛色/耳型/眼色保持）。
3. **异步任务 1-2 分钟**：批量 4 候选约 4-8 分钟；幂等与断点恢复已实现。
4. **平台数据生命周期**：聚合平台无公开删除端点，生成结果默认保存在平台 CDN；实验仅使用合成素材，真实照片上传前需用户确认接受此策略（M4 若接入需在 UI 明确告知）。

## M4 冻结决策（生成侧输入）

- 生成参数：`gpt-image-2`、`size=auto`、浅灰均匀背景（便于色键）、四候选、锁定特征注入 prompt。
- 资产管线：生成 RGB → 色键去背景 → RGBA 透明资产 →（可选 rembg 兜底）。
- 闭眼图层：图生图路线（基于已接受候选）为优先路线，需真实样本确认。
- 任务层：幂等 key（prompt+ref_sha256+index）、tasks.jsonl 断点、errors.jsonl 分类。

## 未验证范围

- 真实宠物照片的身份保持与主人确认（等待用户提供 3-5 张照片）。
- rembg 混合背景路线（需要下载模型，CPU 可跑）。
- 闭眼图层的眼部对齐质量（需人工比对）。
