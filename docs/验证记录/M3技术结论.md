## 关键技术结论

1. **gpt-image-2 输出不透明 RGB** → 桌宠资产必须走 rembg/色键去背景。
2. **rembg 语义分割优于色键**（色键在浅色毛+浅背景时过度抠图）。
3. **身份保持依赖提示词 + 参考图**，毛色/花纹保持可靠，神态细节为迭代优化方向。
4. **平台可靠性**：聚合平台偶发长时间不可达（已见 ~30 分钟故障），必须自动重试 + 断点恢复；无公开删除端点，真实照片生命周期需在 UI 明确告知。
5. 异步任务 1-2 分钟/张，四候选约 4-8 分钟。
