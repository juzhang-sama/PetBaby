# Win10 兼容性检查清单

> 目的：在当前 Win11（build 26200）之外，验证 release 构建在 Windows 10 真机/虚拟机上的核心链路。当前开发机无 Win10 环境，本清单供用户在 Win10 机器上逐项验证。

## 前置条件

- Windows 10（建议 22H2 及以上；如为 LTSC 需确认已安装 WebView2 Runtime）。
- 运行方式：复制 release 可执行文件 `apps/desktop/src-tauri/target/release/desktop-pet.exe` 到目标机器（当前 `bundle.active = false`，未生成安装包；如需安装包再启用 NSIS 构建）。
- 若目标机器无 WebView2 Runtime，先安装 Evergreen Runtime（微软官网下载）。

## 验证项

| 编号 | 场景 | 操作 | 预期 |
|---|---|---|---|
| W-01 | 启动 | 运行 desktop-pet.exe | 托盘图标出现，无报错弹窗 |
| W-02 | 宠物显示 | 启动后查看桌面 | 宠物在桌面可见，透明背景无黑块/白块 |
| W-03 | 拖拽 | 按住宠物拖动 | 宠物跟随鼠标，松手后停在目标位置；下次重启位置保持 |
| W-04 | 透明穿透 | 点击宠物周围透明区域 | 点击穿透到后方窗口；点击宠物本体可拖动 |
| W-05 | 多宠切换 | 托盘→设置→切换宠物 | 桌面宠物随之更换，图片与所选宠物一致 |
| W-06 | 托盘 | 托盘菜单显示/隐藏/设置/退出 | 各菜单项工作正常；退出后进程完全结束 |
| W-07 | 全屏避让 | 打开全屏应用（视频/游戏） | 宠物自动隐藏；退出全屏后自动恢复 |
| W-08 | 离线可用 | 断开网络重启 | 已有宠物正常显示，不依赖网络 |
| W-09 | 资产损坏 | 删除 active pet 的 body.png 后重启 | 显示占位图形，不崩溃 |
| W-10 | 创建闭环 | 设置→创建宠物（需配置 SaaS 服务地址，如启用令牌需填写） | 生成→预览→编译→上桌面全流程可用 |

## 注意事项

- Win10 与 Win11 的透明窗口/DWM 行为可能有差异；若 W-02/W-04 异常，记录截图并回报。
- 若目标机 WebView2 版本较旧，优先更新 Evergreen Runtime 后复测。
- 建议同时观察 30 分钟以上挂机内存是否持续增长（MVP 发布前还有 8 小时冒烟项）。
