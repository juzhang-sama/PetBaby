## 补充说明

- 创建流程定稿为单候选：生成 1 个候选 → 满意则编译上线；不满意则同一宠物重新生成；放弃则删除记录并清理产物。
- 测试照片：用户提供的三只真实宠物（见过/建国），已在上游 M3 验证生成质量。
- API Key：首次使用时在创建向导"保存 Key"输入（应用内保存到本地数据库，不写入仓库）。
- Release 复测（2026-08-05）：修复 release 专属 CSP 问题（`script-src 'unsafe-eval'`、`worker-src blob:`、`connect-src data: blob:`）后，release 构建下宠物显示、切宠、命中区域、动画均正常。
- Win10 真机兼容：待测，清单见 `docs/验证记录/Win10兼容性检查清单.md`。
