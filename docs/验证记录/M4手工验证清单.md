- 使用真实 Tauri 应用和唯一隔离 app-data；记录提交 SHA、Windows/Node/Rust 版本与 PID 树。
- 上传只使用仓库内非个人合成素材。API Key 只保存在应用本地，不写入仓库、截图或验收记录。

- 故障注入不得破坏内置 `pet-live2d-v1` 或只读 `creation-content`，不得递归删除 `app_data/pets` 根目录。
