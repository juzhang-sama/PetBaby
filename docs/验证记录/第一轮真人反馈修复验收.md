# 第一轮真人反馈修复验收

## 1. 范围与结论

本轮处理第一轮真人测试确认的四类问题：停用错误的整图眨眼、修复创建草稿误判、修复认领成功后的导航，以及把双窗口模式收敛为唯一常驻陪伴模式并加入 Win+D 非侵入式恢复。

代码与自动化验证已经完成，结论为：**自动化通过，等待修复后的真实 Tauri 复测**。本记录不把自动化测试冒充真人 GUI 验收。

## 2. 已实施行为

### 2.1 眨眼冻结

- 删除 `PetStage` 的自动眨眼时间线和三类 renderer 的视觉眨眼入口。
- static PNG、animated image 和 Live2D 都不再通过整张画布缩放模拟闭眼。
- 设置页移除眨眼间隔滑杆。
- `blinkIntervalScale` 仅作为旧持久化数据的休眠兼容字段保留，读取、保存和切宠不会丢字段，但不会影响画面。

### 2.2 创建草稿事实收敛

- 长期草稿必须是 upload/composer、pet lifecycle 为 draft、`completed_at IS NULL` 且不是当前宠物。
- ready 且已有 `completed_at` 的正式宠物若残留非终态 session，进入创建入口或开始创建前会在事务内收敛为 completed。
- ready-null、active 等矛盾事实返回明确错误，不通过放宽 abandonment 删除保护来绕过。
- “正式宠物不能被放弃”的安全边界保持不变。

### 2.3 认领成功导航

- 切换到已认领宠物成功后，先刷新目录，再返回创建入口上一级。
- 新认领宠物完成并切换成功后执行相同行为。
- 失败、迟到结果或视图已离开时不触发返回。

### 2.4 唯一常驻模式

- 设置页和托盘均移除 companion/desktop 选择，只保留托盘“显示或隐藏”。
- 旧 `mode=desktop` preference 读取后归一为 companion，任何窗口模式写回也只保存 companion。
- 兼容命令收到 legacy desktop 请求时归一为 companion；启动不再执行 WorkerW/BottomFallback 恢复。
- 默认显示；手动隐藏保留；同屏独占全屏自动隐藏，退出全屏只在用户未手动隐藏时恢复。

### 2.5 Win+D 安全恢复

- 750ms 全屏事实循环结算后读取 `IsWindowVisible`、`DWMWA_CLOAKED` 与 topmost 状态。
- 仅在 canonical 状态明确“应该显示”时，使用 `ShowWindow(SW_SHOWNA)` 和 `SetWindowPos(HWND_TOPMOST, ... SWP_NOACTIVATE)` 重申显示。
- 手动隐藏、全屏 suppression、transition 或退出期间不会恢复。
- 同一次 Shell cloak 最多重申一次；cloak 清除后才重新布防。
- 不使用 `SetParent`、WorkerW 重挂、Explorer 消息、Shell 重启、focus 或 foreground 抢占。

## 5. 修复后真人复测清单

以下项目尚未在本轮由 Codex 启动真实应用执行：

1. 连续观察宠物至少 60 秒，确认不再出现整图瞬间缩小；呼吸和整体轻摆仍正常。
2. 在已有正式宠物的数据库上打开“引导组合”，确认不再出现错误的上次创建弹窗；真实 draft 仍能继续或放弃。
3. 分别对已认领宠物和新模板点击“切换到它”，确认成功后返回创建入口上一级。
4. 验证设置页和托盘没有模式选择，只保留托盘手动显隐；重启后旧 desktop 偏好不再进入桌面宿主路径。
5. 验证普通窗口、同屏独占全屏、退出全屏、手动隐藏、Win+D、再次 Win+D/切回应用的组合。Win+D 若被当前 Shell 持续 cloak，应记录诊断和平台限制，不得用侵入式方案强解。

任一项目失败时停止验收，保存界面、日志和操作顺序，再做最小修复。

## 6. 文档回溯结论

旧 `第一轮测试-五项功能统一验收.md` 中“30 秒眨眼计数”和“Windows 双窗口模式”真人清单已被本轮产品决策废止，不再作为当前验收要求。资料编辑、尺寸、多 renderer 呼吸/反馈校准、生成失败/编译失败、release 性能与安装环境仍是有效后续验证项。

当前项目已经完成早期技术探针和主要 MVP 功能闭环，可以进入迭代优化阶段；但还不能称为公开发布就绪。发布前仍需完成：M4 破坏性 GUI 边界、release/安装/fresh machine、8 小时内存趋势、Windows 10 真机，以及密钥与照片生命周期的后端服务化。

头部跟随、眼球、眨眼、嘴部动作属于明确冻结的素材专项；AI 助手、声音和主动养成属于产品后续迭代，不是当前版本遗漏。
