## 补充记录（2026-08-03）

- W-01/W-02/W-03：用户实测通过。
- W-04/W-05 初版未通过原因（`scripts/诊断窗口状态.ps1` 确认）：当前设备不存在 `SHELLDLL_DefView`；explorer 创建了 18 个隐藏小 `WorkerW`；`FindWindowW` 对该桌面层窗口返回 0；Progman 对 `0x052C` 消息无响应（无新 WorkerW 生成、无子窗口）。标准 WorkerW 方案在当前设备物理不可行。
- 解决：桌面模式改为**置底模拟**（提交 `03dd9c2`）——移除 `WS_EX_TOPMOST` + `SetWindowPos(HWND_BOTTOM)`，不依赖 Progman/WorkerW。效果：普通窗口永远盖住宠物，全部最小化/关闭后宠物可见；explorer 重启不影响窗口（无父子依赖）。
- 拖拽触发 Windows 分屏（Aero Snap）bug 已修复：拖动改为前端手动 `setPosition`（提交 `bec1ccf`），不再走系统拖动，永不触发分屏。
- 已知限制：Explorer 重启后系统托盘图标不会自动重建（muda 无 TaskbarCreated 机制），M1 处理。
