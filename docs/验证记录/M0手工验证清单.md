## 补充记录（2026-08-03）

- W-01/W-02/W-03：用户实测通过。
- W-04/W-05 未通过原因（已用 `scripts/诊断窗口状态.ps1` 确认）：当前设备不存在 `Progman` 与 `SHELLDLL_DefView` 顶层窗口（explorer 正常运行，但 18 个 `WorkerW` 全部为隐藏小窗口，非桌面图标层）。`find_desktop_workerw()` 的 `FindWindowW("Progman")` 直接失败，`SetParent` 从未执行，托盘切换始终返回 `Unavailable("Progman window not found")`。WorkerW 方案在当前设备物理不可行，可能由第三方桌面工具替换了桌面层导致。
- 拖拽触发 Windows 分屏（Aero Snap）bug 已修复：拖动改为前端手动 `setPosition`（提交 `bec1ccf`），不再走系统拖动，永不触发分屏。
