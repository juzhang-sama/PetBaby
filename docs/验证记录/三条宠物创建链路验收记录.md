## 6. 本轮 TDD 修复

1. Tauri 资源 glob 打包会扁平化 `creation-content`：改为目录映射并增加配置契约测试。
2. 单个认领模板内容损坏会阻塞整个目录：增加 Rust RED、`unavailableReason` 契约和 UI 局部禁用。
3. 组合 restore 已恢复 recipe/步骤但显示空身体文案：恢复态文案与事实对齐。
4. candidateReady 后端已锁定但 UI 仍允许返回：锁定前后导航，保留 draft 返回修改。
5. Windows EOL 导致默认 Live2D cdi3 清单哈希漂移：增加逐文件真实 SHA 契约、固定正式 JSON EOL 并更新 cdi3 哈希。
6. 认领目录仅用错误字符串区分全局/局部失败：改为显式安全/File I/O/内容错误类型；catalog、invalid path、escape、containment、reparse、文件类型、bounded read 和 identity/TOCTOU 全目录 fail-closed；可信模板内单资产 NotFound/普通 I/O 及 hash、PNG、motion 内容损坏只禁用单模板。
7. upload 初始 draft 没有直接可见的放弃入口：增加入口并复用既有 confirm、互斥和 `creation_abandon`；测试确认不选文件、不建 job、不调用 provider。
8. motion profile 原子写的 no-replace `MoveFileExW` 未支持 extended-length 路径：复用项目既有 Windows 路径编码，并增加目标路径小于 260、临时路径大于 260 的精确回归。
9. debug capture 最初不能由 Sky 正常枚举正式透明桌宠：增加仅在 debug assertions 且精确环境变量下省略两项 stealth style 的纯函数契约；release 和非精确变量仍保持原行为，未改变透明度、尺寸、DPR、位置、always-on-top、WebView、Canvas 或定时器。
10. 固定序列分析曾把随机相位首帧误当 neutral，导致相对 sway 可达 1.4°并撞上预冻结 ±0.8°拟合边界；契约测试先 RED，再显式使用同 formal body/contain 布局的 neutral reference。白底重建继续固定同一 RGB 距离 18，renderer/profile/判据未修改。
