# 首只 Live2D 宠物正式桌面接入验收记录

## 1. 结论

- 验收日期：2026-08-10
- 结果：通过
- 首只原创 Live2D 猫已接入普通 Tauri 桌宠启动路径，不再依赖 `?live2dPreview=1` 开发预览参数。
- 应用启动时如果没有明确的当前宠物，默认加载内置 `pet-live2d-v1`；如果当前会话已经选择了用户宠物，继续尊重原有选择。
- 正式桌面窗口中胸部呼吸和整体轻摆持续生效；拖拽、放下恢复、全屏自动隐藏与退出全屏恢复均通过。

## 2. 接入方式

新增 `runtime/startup-pet.ts`，负责两项职责：

1. 在无当前宠物时选择已验收的内置 Live2D 包；有当前宠物时继续走已安装资产链路。
2. 从 `/builtin-pets/pet-live2d-v1/` 读取 manifest 和资源，交给现有 `loadLive2DAsset` 完成 SHA-256 校验、模型引用重写和 Blob URL 生命周期管理。

普通启动的失败回退仍然保留：

- Live2D 模型初始化失败时，由现有渲染引导层回退到 manifest 的 `preview.png`。
- 内置 manifest 本身无法读取时，直接使用内置 `preview.png` 静态显示。
- 用户安装资产的加载与回退逻辑保持不变。
