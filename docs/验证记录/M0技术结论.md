## M1 冻结决策

- **保留当前实现**：透明窗口 + SetWindowRgn 命中区域 + WS_EX_NOACTIVATE/TOOLWINDOW 扩展样式、原子 JSON 偏好存储、RenderScheduler 档位、750ms 全屏探针（证据：三组性能采样 idle/hidden CPU P95 均 0%）。
- **仅保留实验模式**：WorkerW 桌面模式，作为可降级能力；失败不阻止 M1。
- **M1 重点关注**：空闲私有内存 156 MB 高于 120 MB 目标，需在 M1 记录内存构成（WebView2 基线 vs 应用自身）并评估优化空间；交互状态的真实拖拽采样待人工补采。

- 125%/150%/200% DPI 与混合 DPI 双屏：未在真实环境验证命中区域缩放。
- 睡眠/唤醒/锁屏恢复、Explorer 重启后桌面模式恢复：待人工执行 W-05。
- 真实拖拽交互下的 CPU 采样：自动化环境无人工操作，interaction.csv 为参考值。
