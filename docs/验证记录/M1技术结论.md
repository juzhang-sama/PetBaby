# M1-P0 运行时技术结论

## 阶段判定

- 总体：有条件通过，可进入 M2（内存基线超分析线，需 M2 关注）
- P0 运行时：通过（apps/desktop 结构、PlatformAdapter 收敛、SQLite 迁移、宠物资料库、PNG 导入、生命周期、降级恢复均有测试覆盖）
- 资产隔离：通过（损坏/缺失资产不阻塞启动，前端占位图形）
- 崩溃恢复：通过（preferences 损坏回退默认、SQLite 损坏自动备份重建，均有单测）
- 性能：有条件通过（CPU 达标；空闲内存 263 MB 超 180 MB 分析线）

## 性能回归（debug 构建）

- 空闲 CPU P95 0.156%（预算 <=1%）通过；隐藏 CPU 0% 通过
- 空闲内存峰值 263.08 MB（M0 为 156 MB），超 180 MB 分析线：SQLite bundled + 新增 Rust 代码 + debug 未优化
- 8 小时无增长测试：本次仅分段采样（600 秒无增长趋势），完整挂机测试待人工执行（命令见 `性能基线.md`）

## M2 冻结决策

- **保留当前实现**：SQLite 版本化迁移、PetRepository/ActivePetSession、manifest v1、PNG 导入管线、资产健康三态、preferences/SQLite 双回退、托盘三菜单、settings 窗口。
- **M2 重点关注**：
  1. 空闲内存构成分析（release 构建复测 + WebView2 基线 vs SQLite vs 应用）；设置窗口关闭后释放资源验证
  2. 领域事件、`energy/mood/bond` 状态、渲染档位接入（`RenderTier` 已就绪）
  3. 分层宠物资产（`layered-v1`）与呼吸/眨眼动画
  4. 完整 8 小时内存趋势（人工挂机）
