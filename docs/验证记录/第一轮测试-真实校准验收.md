结果：17 个测试文件通过，248 passed、0 failed、0 skipped，exit 0。

自动化组合证据包括：

- 呼吸幅度、眨眼间隔和反馈强度经过 canonical 校验后，沿 host/slot/stage 传入当前宠物 runtime；renderer 替换与切宠回滚不会串用对象或配置。
- static PNG、animated image 与 Live2D 均消费呼吸/眨眼校准；Live2D 优先使用语义眼部参数，缺失时使用受限的 canvas 纵向闭合 fallback。
- 点击反馈强度缩放既有 particle、shake、bounce 等视觉量，不改变行为选择与 scheduler tier。
- hidden/paused 不推进呼吸与眨眼时间轴；恢复首帧不把隐藏期间绝对时间当作 delta，不累积突发补帧。
- preview、restore、feedback、commit 协议绑定 `requestId` 与 `petId`，处理超时、迟到响应、重复 ID、切宠 revision 和 listener teardown。
- reset 只预览，后端 save 成功后才以 canonical 返回值 commit；save/commit/reconcile、取消、切宠、BFCache 和原生关闭事务的顺序由可执行测试覆盖。
- 设置页关闭会等待不可取消的保存事务稳定；仅 restore 使用有限等待。原生 close 被拒绝时保留控制器和监听器供重试。

这些证据验证的是确定性代码契约，不等于真人看到实际宠物动画、实际窗口关闭或系统资源占用。
