所以：**「L1 生成质量可用」这次拿到了证据；「L1 端到端可安装 + 动态自然」仍未验。**

## 3. 机械指标（全部干净）

| 指标 | 实测 | 判据 |
| -- | -- | -- |
| `partialAlphaRatio` | 4/4 均为 **0.0** | ≤ 2% |
| `largestComponentShare` | 4/4 均为 **1.0** | 主体单一连通域，无飞块 |
| alpha 边距最小值 | 128px（2048 的 6.3%） | ≥ 2% |
| 产物尺寸 | 4/4 均 2048×2048 | 1024–2048 |
| 审计 schema | 4/4 为 **V1** | — |
| 可见颜色数（S1 实测） | **31** | V1 不校验色数 |

注意：`pixel-style-v1` 的 `postprocess` 未配置调色板量化 → `palette_report is None` →
产出 **V1 审计**，因此 Rust `pixel_avatar_builder.rs:68` 的
「可见颜色数必须相等且 ≤24」检查走 `Option::is_some_and` 短路，**实际不生效**。
本次产物 31 色，超出 24 也没被拦。**不是本次验收的失败项**，但说明该约束在当前风格上形同虚设。

## 4. 人眼判定（权威判据）

机械指标只排雷。逐张肉眼结论：

- **S1 短毛猫**：白身 + 额顶黑斑 + 黑尾，三处身份特征全部保留，一眼是同一只。偏差：原图瞳色偏琥珀，产物为蓝灰；被轻微幼化。
- **S2 长毛猫**：蓬松白毛、扁脸、绿灰眼、蓬尾——波斯体型特征准确。偏差：同样幼化。
- **S3 短毛犬**：比格三色分布（黑背鞍 / 黄褐 / 白）、垂耳、白鼻梁、**连项圈都保留**。保真度最高的一张。
- **S4 长毛犬**：金褐色、垂耳、蓬毛、深色眼、浅色口鼻——金毛特征齐。偏差：**幼化最明显**，原图是成年金毛，产物偏幼犬。

**共性偏差（4/4 都存在，属风格设定而非 bug）**：

1. **全身幼化 / 大头大眼化**——成年猫狗被画成幼体比例。
2. **姿态被规范化为正面坐姿**。S3 原图是侧身站姿，产物是正面坐。这是产品需要的统一取景，属预期。
3. 眼部整体偏大偏"圆萌"。

以上都不影响「身份可辨认」，但**如果想提高"像不像"，这三条是首要调优方向**（prompt / style pack，不是链路问题）。
