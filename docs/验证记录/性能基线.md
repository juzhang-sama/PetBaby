## 预算判断

- 空闲 CPU P95 预算：`<= 1%` —— 通过（实测 0%）

# M1 性能回归（2026-08-03）

## 测试环境

- Windows 版本：Windows 11 专业版 10.0.26200
- CPU/内存：Intel Core i5-14600KF、32 GB RAM、20 逻辑处理器
- WebView2：150.0.4078.105
- 构建类型：debug；M1 新增 SQLite（rusqlite bundled）与宠物资料库

| 状态 | 时长 | CPU P95 | 私有内存峰值 | 进程峰值 | 结论 | CSV |
|---|---:|---:|---:|---:|---|---|
| 空闲 M1 | 300 秒 | 0.156% | 263.08 MB | 8 | 有条件通过 | `性能采样/idle-m1.csv` |
| 隐藏 M1 | 300 秒 | 0% | 222.93 MB | 8 | 通过 | `性能采样/hidden-m1.csv` |

## M1 预算判断

- 空闲 CPU P95：`<= 1%` —— 通过（0.156%，SQLite/校验逻辑可忽略）
- 隐藏 CPU：无持续占用 —— 通过（0%）
- 空闲私有内存：263 MB，**高于 180 MB 分析线**。较 M0（156 MB）增加约 107 MB，主要来自：
  - SQLite bundled 库与连接（约 20-40 MB 量级）
  - M1 新增 Rust 代码与 debug 未优化内存
  - WebView2 基线
  M1 结论要求：进入 M2 前评估 release 构建与按需连接关闭；M2 阶段设置窗口关闭后应释放资源。
- 连续八小时无单向内存增长：本次会话仅提供分段采样（idle-m1 300s + hidden-m1 300s 无增长趋势）；完整 8 小时挂机测试需人工执行，命令：
  `powershell -File scripts/测量桌宠资源.ps1 -RootPid <PID> -State idle-m1 -DurationSeconds 28800`
