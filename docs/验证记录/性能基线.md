# M0 性能基线

## 测试环境

- Windows 版本：Windows 11 专业版 10.0.26200（`Get-CimInstance Win32_OperatingSystem`）
- CPU/内存：Intel Core i5-14600KF、32 GB RAM、20 逻辑处理器（`Get-CimInstance Win32_ComputerSystem`）
- WebView2：150.0.4078.105（`npm run tauri info`）
- 构建类型：debug

| 状态 | 时长 | CPU P95 | 私有内存峰值 | 进程峰值 | 结论 | CSV |

| 隐藏 | 300 秒 | 0% | 152.20 MB | 8 | 通过 | `性能采样/hidden.csv` |

## 预算判断

- 空闲 CPU P95 预算：`<= 1%` —— 通过（实测 0%）
- 交互 CPU P95 预算：`<= 3%` —— 待人工拖拽补采（当前 0% 为无交互参考值）
- 空闲私有内存目标：`<= 120 MB` —— 未达标（156 MB）；低于 `180 MB` 强制分析线，属于 WebView2 基线开销，需在 M1 记录内存构成并评估是否可接受
- 隐藏状态：不得存在高频轮询造成的持续 CPU 占用 —— 通过（实测 0%，隐藏后 WebView 定时器未产生持续占用）

结论只能写“通过”“有条件通过”或“未通过”，并引用 CSV；不能使用单张任务管理器截图替代采样。
