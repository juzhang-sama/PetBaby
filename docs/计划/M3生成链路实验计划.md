# 桌面宠物 M3 生成链路实验计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `subagent-driven-development`（推荐）或 `executing-plans` 执行本计划；本阶段是独立实验工具，不直接进入桌宠主流程。

**Goal:** 用单张正面宠物照片产出主人可辨认的"招牌画风"卡通候选，并验证云端任务可靠性、背景去除、闭眼图层与数据生命周期。实验结论以**主人确认**而非相似度分数为准。

**Architecture:** 独立实验工具 `services/appearance-generation/`（Python），只做生成实验：输入参考图 + 身份特征 → 候选生成 → 后处理 → 评估。不动 `apps/desktop` 主流程。供应商通过统一适配层抽象（当前供应商：聚合引擎 lk888.ai / gpt-image-2）。

**Tech Stack:** Python 3.12、httpx、Pillow、numpy；本地抠图用 `rembg`（onnxruntime，CPU 可跑）或色键+羽化两套方案对比。

## Global Constraints

- API Key 只从环境变量 `LK888_API_KEY` 读取；`.gitignore` 排除所有密钥与本地配置；代码仓库零密钥。
- 参考图仅用于实验任务；任务完成后平台侧不保留策略需在结论中记录（平台为第三方聚合，数据生命周期以平台政策为准，M3 记录实际可验证的部分）。
- 不修改 `apps/desktop`；实验结论以 JSON + 评估表形式输出到 `services/appearance-generation/output/`。
- 失败任务自动退款（平台行为），实验脚本需记录错误类型用于分类。
- TDD：纯逻辑（prompt 构建、过滤、排序、后处理）先写失败测试。

class GenerationProvider(Protocol):

### Task 2: 背景去除后处理（透明资产）

**Files:**
- Create: `src/postprocess.py`、`src/postprocess.test.py`

**Interfaces:**
```python
def remove_background(image: Image.Image, method: str = "auto") -> Image.Image  # RGBA
# auto: 优先色键（统一灰/白背景），失败回退 rembg
def is_probably_transparent(image: Image.Image) -> bool
```
已知约束：gpt-image-2 输出不透明 RGB。方案 A 色键（背景为接近纯色时可靠）；方案 B rembg（onnxruntime CPU，需下载模型 ~170MB，首次联网获取）。两者对比记录在结论。

- [ ] **Step 1: 失败测试**：构造纯色背景图 → 色键去除后 alpha 边缘正确；混合背景 → rembg 路径。
- [ ] **Step 2: 实现两方案**（色键：背景色估计 + 阈值 mask + 羽化；rembg：`rembg.remove`）。
- [ ] **Step 3: 用 Task 1 冒烟产物实测**：输出 `output/transparent/`，人工检查边缘质量。
- [ ] **Step 4: 提交** `feat: background removal post-processing`
