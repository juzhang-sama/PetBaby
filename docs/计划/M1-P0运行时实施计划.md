# 桌面宠物 M1-P0 运行时实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `subagent-driven-development` (recommended) or `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 M0 探针收敛成可靠的单宠 P0 运行时：平台适配收敛、资产清单契约、SQLite 存储、宠物资料库、PNG 导入管线、生命周期与崩溃恢复，并产出性能回归基线。

**Architecture:** 按总体路线图迁入稳定目录 `apps/desktop`。Rust 侧新增 `platform`（收敛）、`pets`（资料库）、`runtime_assets`（清单与校验）、`storage`（SQLite、恢复快照）；前端 `src/runtime` 收敛为 `apps/desktop/src/runtime`。桌面模式不进入 M1（M0 结论：环境限制，未通过）。

**Tech Stack:** 沿用 M0 锁定版本；新增 `rusqlite = "0.32"`（bundled）、`sha2 = "0.10"`。

## Global Constraints

- 桌面模式移除出范围；`WindowMode` 保留类型但托盘只提供陪伴模式。
- 单宠激活：`ActivePetSession` 同一时间只允许一个 `PetRuntimeInstance`。
- 资产损坏不阻塞启动：启动时校验清单，损坏资产标记并降级，其余宠物可用。
- 断网不影响本地宠物：M1 不新增网络依赖。
- 所有领域数据使用 `schemaVersion` 字段；SQLite 用版本化迁移。
- TDD：纯逻辑先写失败测试；Windows 系统能力补充人工验证记录。
- 每个 Task 完成后独立提交；未通过 M1 闸门前不开始 M2。
