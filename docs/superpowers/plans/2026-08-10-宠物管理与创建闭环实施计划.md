# 宠物管理与创建闭环实施计划

> **供智能代理执行：** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 逐任务执行本计划。步骤使用复选框跟踪；每个任务必须完成红灯、绿灯、完整回归和独立提交。

**目标：** 把内置 Live2D 猫、用户宠物管理和单候选创建流程做成本地可恢复的完整 MVP，并保证切换失败时桌面上的原宠物始终保留。

**架构：** Rust 端以同一个 SQLite 连接为权威状态，新增当前选择、统一目录和安全删除三个小型服务；桌面宠物窗口新增可回滚的运行时槽和切换协调器，设置窗口只通过带 `requestId` 的 Tauri 事件发起切换。创建状态从生成任务、候选、运行时变体和资源健康度投影，接受候选复用同一热切换提交边界。

**技术栈：** Rust 2021、Tauri 2.11、rusqlite 0.40、TypeScript 7、Vitest 4、Vite 8、SQLite、Live2D Cubism SDK for Web。

## 全局约束

- 内置宠物固定 ID 为 `pet-live2d-v1`，是虚拟目录项，不写入普通 `pets` 表，UI 和后端均禁止删除。
- 跨重启当前选择只使用 SQLite `state` 表键 `app:active_pet_id`；`ActivePetSession` 只是已提交状态的进程内镜像。
- 切换必须先加载并验证候选，再替换当前宠物；加载、首帧或持久化失败必须恢复原宠物和原选择。
- 创建流程固定为单候选；尚未提交的上传表单不持久化，已创建 pet/job 后必须能跨窗口和应用重启续接。
- 删除当前用户宠物前先热切换到内置猫；只清理目标宠物精确关联的数据库记录、资产目录和 job 目录。
- 不引入 SaaS 后端、账号、云同步、多候选、宠物命名、导入导出或新依赖。
- 不修改 Cubism 源文件、内置猫 manifest、呼吸幅度、整体微动、头部、眼睛和嘴巴行为。
- Windows 专用代码只能位于 `apps/desktop/src-tauri/src/platform/windows.rs`；本计划新增的文件系统和数据库逻辑必须保持跨平台。
- Rust 纯逻辑和 TypeScript 状态机均先写失败测试；系统窗口能力必须补充真实 Tauri 手工验证记录，不能用自动测试代替。

```rust
pub fn inspect_pet_asset(pets_dir: &Path, pet_id: &str) -> AssetHealth {
    let manifest_path = pets_dir.join(pet_id).join("assets").join("manifest.json");
    let status = match validate_asset_manifest(&manifest_path) {
        Ok(()) => "healthy",
        Err(AssetReadError::Missing) => "missing",
        Err(AssetReadError::Corrupt) => "corrupt",
    };
    AssetHealth {
        pet_id: pet_id.to_owned(),
        status,
        manifest_path: manifest_path.to_string_lossy().into_owned(),
    }
}
```


- [ ] **Step 6：实现当前选择服务**

核心类型和提交顺序固定如下：

```rust
pub const BUILTIN_PET_ID: &str = "pet-live2d-v1";
const ACTIVE_KEY: &str = "app:active_pet_id";

#[derive(Debug, Clone, serde::Serialize, PartialEq)]
#[serde(rename_all = "lowercase")]
pub enum RuntimePetSource { Builtin, Installed }

#[derive(Debug, Clone, serde::Serialize, PartialEq)]
#[serde(rename_all = "camelCase")]
pub struct RuntimePetDescriptor {
    pub pet_id: String,
    pub source: RuntimePetSource,
}

pub struct ActivePetService {
    storage: Arc<Mutex<Storage>>,
    session: SharedActivePetSession,
    pets_dir: PathBuf,
}

impl ActivePetService {
    pub fn prepare(&self, pet_id: &str) -> Result<RuntimePetDescriptor, String> {
        if pet_id == BUILTIN_PET_ID {
            return Ok(RuntimePetDescriptor { pet_id: pet_id.into(), source: RuntimePetSource::Builtin });
        }
        self.require_installed_pet(pet_id)?;
        Ok(RuntimePetDescriptor { pet_id: pet_id.into(), source: RuntimePetSource::Installed })
    }

    pub fn commit(&self, pet_id: &str, accepted_variant_id: Option<&str>) -> Result<(), String> {
        self.prepare(pet_id)?;
        let mut storage = self.storage.lock().map_err(|_| "storage lock poisoned")?;
        let tx = storage.db.transaction().map_err(|error| error.to_string())?;
        if let Some(variant_id) = accepted_variant_id {
            let affected = tx.execute(
                "UPDATE appearance_variants SET accepted = 1
                 WHERE variant_id = ?1 AND pet_id = ?2
                 AND EXISTS (SELECT 1 FROM variants v WHERE v.variant_id = ?1 AND v.pet_id = ?2)",
                rusqlite::params![variant_id, pet_id],
            ).map_err(|error| error.to_string())?;
            if affected != 1 { return Err("candidate does not belong to pet".into()); }
        }
        tx.execute(
            "INSERT INTO state (key, value) VALUES (?1, ?2) ON CONFLICT(key) DO UPDATE SET value=excluded.value",
            rusqlite::params![ACTIVE_KEY, pet_id],
        ).map_err(|error| error.to_string())?;
        tx.commit().map_err(|error| error.to_string())?;
        drop(storage);
        self.session.lock().map_err(|_| "session lock poisoned")?.set_active(pet_id.into())
    }
}
```

`restore` 读取状态键；缺失、用户记录不存在或资源不是 `healthy` 时保存内置 ID，再更新会话镜像。`commit` 必须先提交 SQLite，再更新会话；任何数据库错误都保持旧会话。

`ActiveHarness` 是该模块测试专用 fixture：`new()` 创建独立临时目录、同一个 `Storage`、`ActivePetSession` 和 `ActivePetService`；`insert_pet` 直接插入测试 pet；`with_healthy_pet` 同时写入合法 PNG/manifest、appearance variant 和 runtime variant；`save_active`、`persisted_active`、`session_active`、`variant_accepted` 都只查询这份临时数据库。fixture 实现不得访问用户应用数据目录。

```rust
    let dir = self.jobs_dir.join(job_id);
    std::fs::create_dir_all(&dir).map_err(|error| error.to_string())?;
```

```typescript
export class PetRuntimeSlot implements PetRenderer {
  private active: MountedPetRuntime;
  private viewport: Viewport | null = null;
  private visible = false;

  constructor(private readonly root: HTMLElement, initial: MountedPetRuntime) {
    this.active = initial;
    this.root.replaceChildren(initial.getSurface());
  }

  get activePetId(): string { return this.active.petId; }
  getSurface(): HTMLCanvasElement { return this.active.getSurface(); }

  prepare(candidate: MountedPetRuntime): PreparedRuntimeSwap {
    if (this.viewport) candidate.host.resize(this.viewport);
    candidate.host.setVisibility(this.visible);
    candidate.host.update(0);
    const previous = this.active;
    let activated = false;
    let settled = false;
    return {
      previous,
      candidate,
      activate: () => {
        if (settled || activated) throw new Error("swap is not activatable");
        previous.host.setVisibility(false);
        this.active = candidate;
        this.root.replaceChildren(candidate.getSurface());
        activated = true;
      },
      commit: () => {
        if (!activated || settled) throw new Error("swap is not committable");
        settled = true;
        previous.host.destroy();
      },
      rollback: () => {
        if (settled) return;
        settled = true;
        if (activated) {
          this.active = previous;
          this.root.replaceChildren(previous.getSurface());
          previous.host.setVisibility(this.visible);
        }
        candidate.host.destroy();
      },
    };
  }
}
```

```typescript
async switch(request: PetSwitchRequest): Promise<PetSwitchResult> {
  if (this.busy) {
    return failure(request, "request-stale", "已有宠物切换正在进行");
  }
  this.busy = true;
  let swap: PreparedRuntimeSwap | undefined;
  try {
    const descriptor = await this.ports.prepare(request.petId);
    const runtime = await this.ports.load(descriptor, document.createElement("div"));
    swap = this.slot.prepare(runtime);
    this.ports.probe(runtime.getSurface());
    swap.activate();
    await this.ports.refreshHitRegion();
    try {
      await this.ports.commit(request.petId, request.acceptedVariantId);
    } catch (error) {
      swap.rollback();
      await this.ports.refreshHitRegion().catch(() => undefined);
      return failure(request, "persist-failed", messageOf(error));
    }
    swap.commit();
    return { ok: true, requestId: request.requestId, petId: request.petId };
  } catch (error) {
    swap?.rollback();
    await this.ports.refreshHitRegion().catch(() => undefined);
    return failure(request, classify(error), messageOf(error));
  } finally {
    this.busy = false;
  }
}
```

```typescript
export async function requestPetSwitch(
  petId: string,
  acceptedVariantId?: string,
  ports: SwitchClientPorts = tauriSwitchPorts,
): Promise<PetSwitchResult> {
  const requestId = crypto.randomUUID();
  let resolveResult!: (result: PetSwitchResult) => void;
  const resultPromise = new Promise<PetSwitchResult>((resolve) => { resolveResult = resolve; });
  const unlisten = await ports.listen((result) => {
      if (result.requestId !== requestId) return;
      window.clearTimeout(timer);
      unlisten();
      resolveResult(result);
  });
  const timer = window.setTimeout(() => {
    unlisten();
    resolveResult({ ok: false, requestId, petId, code: "pet-window-unavailable", message: "桌面宠物窗口没有响应" });
  }, 10_000);
  try {
    await ports.emit({ requestId, petId, ...(acceptedVariantId ? { acceptedVariantId } : {}) });
  } catch (error) {
    window.clearTimeout(timer);
    unlisten();
    return {
      ok: false,
      requestId,
      petId,
      code: "pet-window-unavailable",
      message: error instanceof Error ? error.message : String(error),
    };
  }
  return resultPromise;
}
```

```rust
#[derive(Debug)]
struct QuarantinedPath { original: PathBuf, quarantined: PathBuf }

fn quarantine_path(source: &Path, root: &Path, name: &str) -> Result<Option<QuarantinedPath>, String> {
    if !source.exists() { return Ok(None); }
    std::fs::create_dir_all(root).map_err(|error| error.to_string())?;
    let target = root.join(name);
    std::fs::rename(source, &target).map_err(|error| error.to_string())?;
    Ok(Some(QuarantinedPath { original: source.into(), quarantined: target }))
}

fn restore_all(paths: &[QuarantinedPath]) -> Result<(), String> {
    for path in paths.iter().rev() {
        if path.quarantined.exists() {
            std::fs::rename(&path.quarantined, &path.original).map_err(|error| error.to_string())?;
        }
    }
    Ok(())
}
```

源路径只允许是 `app_data/pets/<petId>` 和数据库查出的 `app_data/jobs/<jobId>`；在移动前用规范化父目录检查阻止路径逃逸。移动任一后续路径失败时，立即对已移动列表调用 `restore_all`，数据库事务不得开始。

```typescript
function actionsFor(entry: PetCatalogEntry): PetListAction[] {
  const actions: PetListAction[] = [];
  if (!entry.isCurrent) {
```

```typescript
import type { CreationResume } from "../pets/pet-catalog-contract";

export type CreationStep = "upload" | "generating" | "review" | "confirm" | "complete";

get petId(): string | null { return this.currentPetId; }

restore(snapshot: CreationResume): void {
  this.currentPetId = snapshot.petId;
  this.jobId = snapshot.jobId;
  this.variantId = snapshot.variantId;
  switch (snapshot.status) {
    case "generating": this.step = "generating"; break;
    case "generationFailed": this.step = "upload"; break;
    case "awaitingConfirm":
    case "compileRetryable": this.step = "review"; break;
    case "awaitingActivation": this.step = "confirm"; break;
    case "ready": this.step = "complete"; break;
    case "corrupt": throw new Error("corrupt pet is not resumable");
  }
}

async submitSingle(): Promise<void> {
  if (!this.photoBytes) throw new Error("photo required");
  if (!this.currentPetId) throw new Error("pet id required");
  this.jobId = await this.store.genStart(
    this.currentPetId, buildPrompt(this.species), bytesToBase64(this.photoBytes),
  );
  this.variantId = this.jobId;
  this.step = "generating";
}

async poll(): Promise<CreationResume> {
  if (!this.currentPetId) throw new Error("pet id required");
  const snapshot = await this.store.resume(this.currentPetId);
  this.restore(snapshot);
  return snapshot;
}

async compileCandidate(): Promise<{ manifestPath: string; degraded: boolean }> {
  if (!this.currentPetId || !this.variantId) throw new Error("candidate required");
  try {
    const result = await this.store.compile(this.currentPetId, this.variantId);
    this.step = "confirm";
    return result;
  } catch (error) {
    this.step = "review";
    throw error;
  }
}

async activateCandidate(): Promise<void> {
  if (!this.currentPetId || !this.variantId) throw new Error("candidate required");
  const result = await this.store.switchPet(this.currentPetId, this.variantId);
  if (!result.ok) throw new Error(`${result.code}: ${result.message}`);
  this.step = "complete";
}
```

`compileCandidate` 成功只进入 `confirm`，不设置 complete；失败保持 `review`。`poll` 只观察当前最新 job，成功进入 review，失败进入 upload 并保留 `currentPetId` 供重新上传。
