# 猫狗共用身份合同实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (\`- [ ]\`) syntax for tracking.

**Goal:** 将当前 pixel 照片路线的身份合同从猫专用扩展为猫狗共用，并保持动作系统单一。

**Architecture:** 只修改 pixel 路线的物种约束。分析 profile 使用 \`cat | dog\`，后续补全保留分析出的物种；运行时动作语义和播放器不按物种分叉。旧 Live2D/历史照片路线继续保持现状。

**Tech Stack:** Python 3、Rust/Serde、TypeScript/Vitest。

## Global Constraints

- 仅支持 \`cat\` 和 \`dog\`，其他物种必须拒绝。
- 不新增独立物种识别服务。
- 不新增猫狗两套动作状态机。
- 修改纯逻辑前先写失败测试。
- 不把尚未实测的狗生成、动作帧或安装能力描述为已完成。
