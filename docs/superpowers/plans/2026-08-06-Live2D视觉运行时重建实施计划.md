# Live2D 视觉运行时重建实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保留 Tauri/Rust 平台壳、宠物档案、创建流程、行为状态和窗口物理的前提下，以官方 Cubism SDK for Web 重建 Live2D-first 视觉运行时，并在高还原身份能力成熟前保留静态 PNG 回退。

**Architecture:** 宿主通过通用 `PetRenderer` 驱动 `Live2DRenderer` 或 `StaticPngRenderer`，`PetPresentationController` 负责语义动作仲裁，`WindowMotionController` 单独负责桌面窗口位移。Manifest v2 描述 Live2D 模型入口、语义映射、文件摘要和许可证；旧 manifest v1 只进入静态回退，不再执行 Mesh 变形。

**Tech Stack:** Tauri 2.11、Rust、TypeScript 7、Vite 8、PixiJS 8、Vitest 4、官方 Live2D Cubism SDK for Web、WebGL/WebView2、SQLite。

## Global Constraints

- 第一版形态固定为正面坐姿，优先表情、视线、呼吸、耳尾物理和窗口反馈。
- 高度还原用户宠物身份优先于强制 Live2D；模板不匹配时必须显示高还原静态 PNG。
- 不自动把任意单图宣传为完整 Live2D 模型。
- 不继续扩展 `PetMesh`、`mesh-rig`、`skinning` 和旧视觉关键帧执行器。
- Live2D 内部 Motion 与 Tauri 窗口位移保持分离。
- 第一版只允许数据型模型包，不允许角色包执行任意代码。
- Cubism SDK、Cubism Core、模型、纹理、Motion 和 Expression 必须分别登记许可证。
- Windows 11 先验收，发布前完成 Windows 10 验收。
- 微动画 CPU 长期采样 P95 不高于 3%；Live2D 内存和 GPU 基线必须重新测量。
- 所有新增 Markdown 文件使用中文文件名。
- 不覆盖或回滚工作区中与本计划无关的现有修改。

```ts
export interface CubismAdapter {
  initialize(canvas: HTMLCanvasElement): Promise<void>;
  loadModel(modelUrl: string): Promise<void>;
  resize(width: number, height: number, dpr: number): void;
  update(deltaMs: number): void;
  draw(): void;
  destroy(): void;
}

export function evaluateProbe(input: {
  webgl: boolean;
  nonTransparentPixels: number;
  contextLost: boolean;
}): { ok: true } | { ok: false; reason: string } {
  if (!input.webgl) return { ok: false, reason: "webgl-unavailable" };
  if (input.contextLost) return { ok: false, reason: "context-lost" };
  if (input.nonTransparentPixels === 0) return { ok: false, reason: "blank-frame" };
  return { ok: true };
}
```

- [ ] **Step 4: 实现 v2 类型和分派解析器**

```ts
export interface Live2DSemantics {
  motions: Partial<Record<PetMotion, { group: string; index?: number }>>;
  expressions: Partial<Record<PetExpression, string>>;
  hitAreas: Partial<Record<PetHitArea, string>>;
  parameters: Partial<Record<"eyeOpen" | "eyeBallX" | "eyeBallY" | "angleX" |
    "angleY" | "bodyBreath" | "mouthOpen", string>>;
}

export interface RuntimeAssetManifestV2 {
  schemaVersion: 2;
  renderer: "live2d-v1";
  petId: string;
  variantId: string;
  modelEntry: string;
  previewImage: string;
  files: ManifestFileEntry[];
  semantics: Live2DSemantics;
  license: {
    id: string;
    author: string;
    source: string;
    commercialUse: boolean;
    redistributable: boolean;
  };
}

export type RuntimeAssetManifest = RuntimeAssetManifestV1 | RuntimeAssetManifestV2;

export function parseRuntimeAssetManifest(json: unknown): RuntimeAssetManifest {
  if (typeof json !== "object" || json === null) throw new Error("manifest must be an object");
  const version = (json as { schemaVersion?: unknown }).schemaVersion;
  if (version === 1) return parseManifestV1(json);
  if (version === 2) return parseLive2DManifest(json);
  throw new Error(`unsupported schemaVersion: ${String(version)}`);
}
```

模型包允许扩展名固定为 `.json`、`.moc3`、`.png`、`.motion3.json`、`.exp3.json`、`.physics3.json`、`.pose3.json`、`.userdata3.json`。所有相对路径经过统一 `normalizeAssetPath`，拒绝绝对路径、盘符、空段和 `..`。
