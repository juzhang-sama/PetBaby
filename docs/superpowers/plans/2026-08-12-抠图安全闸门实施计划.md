# 抠图安全闸门实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 保留生成结果原始 alpha，并让所有 `needs-review` 候选在 UI 与后端定稿层同时被阻断，同时保留原图和诊断抠图供重试。

**Architecture:** Rust 负责唯一质量事实、持久化和定稿准入；前端只投影结构化质量报告。先解耦迁移器的 legacy 修复目标与最新版本，再以 v7 为 `appearance_variants` 增加版本化质量报告列；生成阶段在写 motion profile 前完成质量判断，合格候选走动态预览，不合格候选走原图/诊断图静态对比。

**Tech Stack:** Rust、rusqlite、image、serde/serde_json、Tauri 2、TypeScript、Vitest。

## Global Constraints

- `needs-review` 候选不得完成创建，后端必须独立强制拒绝。
- 供应商结果具有有效透明通道时不得调用 `to_rgb8()` 丢失 alpha。
- 不通过修改 tolerance 声称解决浅色主体与浅灰背景同色问题。
- 不把真实用户图片提交到仓库；测试只使用程序生成的合成 fixture。
- 保留原图、诊断抠图和会话，允许重新生成或放弃。
- 不修改现有未提交的 `apps/desktop/src-tauri/Cargo.toml` 和 `docs/新对话开发交接摘要.md`。
- 除非步骤另有说明，Rust 命令从 `apps/desktop/src-tauri` 执行，npm 命令从 `apps/desktop` 执行。

- [ ] **Step 3: 实现类型与 alpha 分支**

```rust
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "camelCase")]
pub enum CandidateQualityStatus { Acceptable, NeedsReview }

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "camelCase")]
pub enum QualityReason {
    ExcessiveTransparency,
    InteriorHoles,
    LowContrastSubject,
    NonUniformBackground,
    InvalidSourceAlpha,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "camelCase")]
pub struct CandidateQualityReportV1 {
    pub schema_version: u32,
    pub status: CandidateQualityStatus,
    pub reasons: Vec<QualityReason>,
    pub opaque_ratio: f32,
    pub transparent_ratio: f32,
    pub partial_alpha_ratio: f32,
    pub visible_bounds: Option<[u32; 4]>,
}

pub fn remove_background(img: &DynamicImage) -> CutoutResult {
    let rgba = img.to_rgba8();
    if rgba.pixels().any(|pixel| pixel[3] < 255) {
        return CutoutResult {
            report: quality_report(&rgba, CutoutStrategy::SourceAlpha),
            rgba,
            strategy: CutoutStrategy::SourceAlpha,
        };
    }
    remove_opaque_background(&img.to_rgb8())
}
```

`quality_report` 必须计算四档 alpha 比例、可见 bbox、内部洞和低对比主体原因；`status` 由 reasons 是否为空决定。色键 tolerance 保持原值，不在此任务调参。
