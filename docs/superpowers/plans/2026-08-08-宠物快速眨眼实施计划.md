# 宠物快速眨眼实施计划

> **供智能代理执行：** 必须使用 `executing-plans` 按任务逐项实施。此计划操作同一个 Cubism 二进制源文件，步骤紧密耦合，不拆分为并行子任务。步骤使用复选框跟踪。

**目标：** 基于现有眼球和虹膜瞳孔，为宠物建立第一版左右眼独立、可同步驱动的自然眨眼。

**架构：** 从嘴部验收版本另存 v7；每只眼新增一个外层 2×2 弯曲变形器，同时包裹同侧眼球和虹膜瞳孔。现有眼球 X/Y 关键形保留在内层，外层只绑定标准眼睛开闭参数。

**技术栈：** Live2D Cubism Editor 5.3.03、CMO3、标准参数 `ParamEyeLOpen` / `ParamEyeROpen`、PowerShell SHA-256 校验。

## 全局约束

- 基准文件 `D:\PetBabyAssets\first-pet\05-cubism-project\pet-live2d-source-v6-mouth-approved.cmo3` 永不覆盖。
- 输出文件固定为 `D:\PetBabyAssets\first-pet\05-cubism-project\pet-live2d-source-v7-blink.cmo3`。
- 不新增或修改 PNG、KRA、PSD 美术素材。
- 不修改鼻子、嘴线、脸型、耳朵、身体、前腿和尾巴。
- 不删除或重建现有眼球 X/Y 关键形。
- 左右眼必须使用独立标准参数；普通眨眼由运行时同步驱动，不制作 Motion。
- 实施前后默认状态固定为：左右眼开闭 `1`、眼球 X/Y `0`、嘴开闭 `0`。
- 出现透明洞、旧眼睛重影或明显白边且缩小闭眼幅度仍不能解决时，停止并回退 v6，不强行继续。

### Task 2：建立左眼眨眼

**文件：**

- 修改：`D:\PetBabyAssets\first-pet\05-cubism-project\pet-live2d-source-v7-blink.cmo3`

**接口：**

- 输入：根级对象 `左眼球` 与 `左虹膜瞳孔`，标准参数 `ParamEyeLOpen`。
- 输出：`左眼眨眼变形器`，包含三个开闭关键形且不删除眼球 X/Y 绑定。

- [ ] **Step 1：创建左眼外层变形器**

在变形器面板同时选中 `左眼球` 和 `左虹膜瞳孔`，创建 2×2 弯曲变形器并命名为 `左眼眨眼变形器`。确认两个对象成为该变形器的子级，另一只眼和脸部对象仍在外部。

- [ ] **Step 2：绑定三个关键形**

选中 `左眼眨眼变形器`，为 `ParamEyeLOpen` 添加 `0`、`0.5`、`1` 三个关键形。`1` 必须保持创建变形器前的原始外观。

- [ ] **Step 3：制作半闭状态**

把参数置于 `0.5`，以眼睛视觉中心为缩放中心，将变形器纵向压缩到原可见眼高的 `45%–55%`；水平宽度不变。确认虹膜随眼球共同压缩。

- [ ] **Step 4：制作闭眼状态**

把参数置于 `0`，继续纵向压缩到原可见眼高的 `8%–15%`。保持眼睛左右端点稳定，允许保留窄暗缝，不允许残留完整圆形瞳孔。

- [ ] **Step 5：单眼往返检查并保存**

执行 `1 → 0.5 → 0 → 0.5 → 1` 两次。检查无透明洞、明显白边、旧眼睛重影、脸部移动或纹理翻转；恢复左眼开闭为 `1` 并保存 v7。

### Task 3：建立右眼眨眼

**文件：**

- 修改：`D:\PetBabyAssets\first-pet\05-cubism-project\pet-live2d-source-v7-blink.cmo3`
