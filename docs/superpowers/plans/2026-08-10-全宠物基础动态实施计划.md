# 全宠物基础动态实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让现有图片创建链路产出的新宠物和已有 schema v1 用户宠物都自动具备胸腹呼吸与轻微摆动，同时保持默认 Cubism Live2D 猫行为不变。

**Architecture:** Rust 在候选后处理阶段生成版本化动作语义，并将图片与动作配置编译为 `animated-image-v1` schema v3 资源；启动恢复阶段原子迁移旧 v1 资源。TypeScript 通过统一 `PetRenderer`/`PetRendererRuntime` 契约加载动态单图，桌面与候选预览共用相同渲染器和中央 `life-v1` 参数。

**Tech Stack:** Rust 2021、Tauri 2.11.5、`image` 0.25.5、Serde/serde_json、TypeScript、Canvas 2D、Vitest 4、Vite 8。

## Global Constraints

- 所有 `ready` 用户宠物必须具备呼吸和微动；动态资源失败时不得静态降级为创建成功。
- 呼吸只改变胸腹安全线以下的局部几何；脸、眼睛和头部不参与局部呼吸变形。
- 微动只做最大 0.7° 旋转和画布宽度最大 0.45% 的水平位移，不改变面部结构。
- `life-v1`：呼吸周期 2800 ms，胸腹最大横向缩放 2.8%，最大纵向位移 1.2%；微动周期 5200 ms。
- 创建界面不增加“生成动画”“启用呼吸”或渲染器类型等用户可见步骤。
- 当前计划不新增引导组合和直接认领 UI；它们以后必须复用 `compile_animated_image`。
- 当前计划不实现转头、眨眼、嘴巴、表情或肢体动作。
- 保留默认 Live2D v2、旧 v1 解析能力和受控静态诊断渲染器；用户宠物的合格完成态必须是 v3。
- 所有生产代码严格执行 RED → GREEN → REFACTOR；每个任务独立提交，禁止混入现有未提交验收文档。
- 除 Task 9 已显式写出 `Set-Location` 外：所有 `cargo` 命令从 `apps/desktop/src-tauri` 执行，所有 `npm` 命令从 `apps/desktop` 执行；每次提交从工作树根目录执行。

```rust
#[derive(Debug, Clone, serde::Serialize, serde::Deserialize, PartialEq)]
#[serde(rename_all = "camelCase")]
pub struct NormalizedRect {
    pub left: f32,
    pub top: f32,
    pub right: f32,
    pub bottom: f32,
}

#[derive(Debug, Clone, serde::Serialize, serde::Deserialize, PartialEq)]
pub struct NormalizedPoint { pub x: f32, pub y: f32 }

#[derive(Debug, Clone, serde::Serialize, serde::Deserialize, PartialEq)]
#[serde(rename_all = "camelCase")]
pub struct MotionProfileV1 {
    pub profile_version: u32,
    pub engine_profile: String,
    pub alpha_bounds: NormalizedRect,
    pub breath_zone: NormalizedRect,
    pub sway_pivot: NormalizedPoint,
}

pub fn generate_motion_profile(image: &image::RgbaImage) -> Result<MotionProfileV1, String> {
    let (width, height) = image.dimensions();
    if width == 0 || height == 0 { return Err("image dimensions must be positive".into()); }
    let mut bounds: Option<(u32, u32, u32, u32)> = None;
    for (x, y, pixel) in image.enumerate_pixels() {
        if pixel.0[3] < 8 { continue; }
        bounds = Some(match bounds {
            None => (x, y, x, y),
            Some((l, t, r, b)) => (l.min(x), t.min(y), r.max(x), b.max(y)),
        });
    }
    let (l, t, r, b) = bounds.ok_or("opaque silhouette is missing")?;
    let alpha = NormalizedRect {
        left: l as f32 / width as f32,
        top: t as f32 / height as f32,
        right: (r + 1) as f32 / width as f32,
        bottom: (b + 1) as f32 / height as f32,
    };
    let w = alpha.right - alpha.left;
    let h = alpha.bottom - alpha.top;
    let profile = MotionProfileV1 {
        profile_version: 1,
        engine_profile: "life-v1".into(),
        alpha_bounds: alpha.clone(),
        breath_zone: NormalizedRect {
            left: alpha.left + w * 0.15,
            top: alpha.top + h * 0.46,
            right: alpha.right - w * 0.15,
            bottom: alpha.top + h * 0.85,
        },
        sway_pivot: NormalizedPoint { x: alpha.left + w * 0.50, y: alpha.top + h * 0.74 },
    };
    validate_motion_profile(&profile)?;
    Ok(profile)
}
```

`validate_motion_profile` 必须拒绝非有限数、`0..1` 越界、倒置矩形、未知版本/引擎、胸腹越出 alphaBounds、胸腹上边界低于 40% 安全线以及摆动轴越出 alphaBounds。`write_motion_profile_atomic` 写入同目录唯一临时文件并 `sync_all`；若目标已存在，则先移到同目录唯一 backup，再把临时文件 rename 为目标。第二次 rename 失败必须恢复 backup，成功后删除 backup；任一路径都清理临时文件，保证 Windows 重试可覆盖而不丢失上一份有效配置。

```rust
#[derive(Debug, Clone, Deserialize, Serialize, PartialEq)]
#[serde(rename_all = "camelCase")]
pub struct RuntimeAssetManifestV3 {
    pub schema_version: u32,
    pub renderer: String,
    pub pet_id: String,
    pub variant_id: String,
    pub image: String,
    pub motion_profile: String,
    pub files: Vec<ManifestFileEntry>,
}

#[derive(Debug, Clone, Serialize, PartialEq)]
#[serde(untagged)]
pub enum RuntimeAssetManifest {
    V1(RuntimeAssetManifestV1),
    V2(RuntimeAssetManifestV2),
    V3(RuntimeAssetManifestV3),
}

pub fn manifest_files(manifest: &RuntimeAssetManifest) -> &[ManifestFileEntry] {
    match manifest {
        RuntimeAssetManifest::V1(value) => &value.files,
        RuntimeAssetManifest::V2(value) => &value.files,
        RuntimeAssetManifest::V3(value) => &value.files,
    }
}

pub fn manifest_identity(manifest: &RuntimeAssetManifest) -> (&str, &str) {
    match manifest {
        RuntimeAssetManifest::V1(value) => (&value.pet_id, &value.variant_id),
        RuntimeAssetManifest::V2(value) => (&value.pet_id, &value.variant_id),
        RuntimeAssetManifest::V3(value) => (&value.pet_id, &value.variant_id),
    }
}
```

`parse_manifest` 对版本 3 必须校验：renderer 精确等于 `animated-image-v1`，`image` 与 `motionProfile` 都经过 `normalize_relative_path`，两者均在 `files` 中，图片扩展名为 PNG，动作配置扩展名为 JSON，角色分别为 `main` 与 `motion-profile`。loader 读取并哈希全部文件，随后对 v3 的动作配置调用 `parse_motion_profile`。

```rust
pub fn compile_animated_image(
    pet_id: &str,
    variant_id: &str,
    cutout_path: &Path,
    motion_profile_path: &Path,
    dest_dir: &Path,
) -> Result<CompileResult, String> {

    image::load_from_memory(&body_bytes).map_err(|e| e.to_string())?;
    let profile_json = std::fs::read_to_string(motion_profile_path).map_err(|e| e.to_string())?;

    std::fs::write(staging.join("body.png"), &body_bytes).map_err(|e| e.to_string())?;
    std::fs::write(staging.join("motion-profile.json"), profile_json.as_bytes()).map_err(|e| e.to_string())?;
    let manifest = build_v3_manifest(pet_id, variant_id, &body_bytes, profile_json.as_bytes());
    std::fs::write(
        staging.join("manifest.json"),
        serde_json::to_vec_pretty(&manifest).map_err(|e| e.to_string())?,
    ).map_err(|e| e.to_string())?;
    loader::validate_asset_directory(&staging)?;
    installer::install_staged_assets(&staging, dest_dir)?;
```

```typescript
export const LIFE_V1 = Object.freeze({
  breathPeriodMs: 2800,
  breathScaleX: 0.028,
  breathShiftY: 0.012,
  swayPeriodMs: 5200,
  swayRadians: 0.7 * Math.PI / 180,
  swayXRatio: 0.0045,
});

export function computeMotionFrame(elapsedMs: number): MotionFrame {
  const breathPhase = 2 * Math.PI * (elapsedMs % LIFE_V1.breathPeriodMs) / LIFE_V1.breathPeriodMs;
  const swayPhase = 2 * Math.PI * (elapsedMs % LIFE_V1.swayPeriodMs) / LIFE_V1.swayPeriodMs;
  return {
    breath: (Math.sin(breathPhase - Math.PI / 2) + 1) / 2,
    swayRadians: Math.sin(swayPhase) * LIFE_V1.swayRadians,
    swayXRatio: Math.sin(swayPhase) * LIFE_V1.swayXRatio,
  };
}

export function breathWeight(normalizedY: number): number {
  const t = Math.min(1, Math.max(0, normalizedY));
  return Math.sin(Math.PI * t);
}
```

`planBreathSlices` 把图片分成 24 条水平带，并把 `breathZone.top/bottom` 强制加入分片边界，禁止任何一条带跨过脸部安全线；每条带再按胸腹的 left/right 切成左侧、胸腹、右侧三段。胸腹矩形外保持 source/destination 几何相同；只有中央胸腹段使用 `breathWeight(t)`，使上下边界权重为 0，中部横向最大扩张 2.8%、纵向最大位移 1.2%。

```typescript
function fakeRenderer(): PetRenderer {
  return {
    load: vi.fn(async () => undefined), resize: vi.fn(), playMotion: vi.fn(() => ({ cancel: vi.fn() })),
    setExpression: vi.fn(), setLookTarget: vi.fn(), setLipSync: vi.fn(), hitTest: vi.fn(() => null),
    setVisibility: vi.fn(), update: vi.fn(), destroy: vi.fn(),
  };
}

function previewHarness() {
  const callbacks = new Map<number, FrameRequestCallback>();
  const renderers: PetRenderer[] = [];
  let nextFrame = 0;
  const requestAnimationFrame = vi.fn((callback: FrameRequestCallback) => {
    const id = ++nextFrame;
    callbacks.set(id, callback);
    return id;
  });
  const cancelAnimationFrame = vi.fn((id: number) => callbacks.delete(id));
  const root = {
    replaceChildren: vi.fn(),
    getBoundingClientRect: vi.fn(() => ({ width: 320, height: 360 })),
  } as unknown as HTMLElement;
  const ports: CandidatePreviewPorts = {
    createRenderer: vi.fn(() => {
      const renderer = fakeRenderer();
      renderers.push(renderer);
      return renderer;
    }),
    requestAnimationFrame,
    cancelAnimationFrame,
    createResizeObserver: vi.fn(() => ({ observe: vi.fn(), disconnect: vi.fn() })),
    devicePixelRatio: () => 1,
  };
  return {
    root, ports, renderers, cancelAnimationFrame,
    get renderer() { return renderers[0]!; },
    fireFrame(timestamp: number) {
      const entry = callbacks.entries().next().value as [number, FrameRequestCallback] | undefined;
      if (!entry) throw new Error("no animation frame queued");
      callbacks.delete(entry[0]);
      entry[1](timestamp);
    },
  };
}
```
