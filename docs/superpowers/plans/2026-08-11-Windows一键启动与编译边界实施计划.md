# Windows 一键启动与编译边界实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 PetBaby 提供可双击、可诊断且不会静默缺失 Cubism 的 Windows 开发启动入口，并用静态契约冻结现有 Windows 原生代码直接使用范围。

**Architecture:** 仓库根目录的 `.cmd` 只负责双击入口、调用 PowerShell 和失败暂停；`scripts` 下的 PowerShell 脚本负责工具链检查、npm 依赖安装、Cubism 准备和唯一的 `tauri dev` 启动。Vitest 读取真实脚本和 Rust 源码进行静态契约验证，Rust 生产代码仅在 Windows `cargo check` 实际发现纯编译错误时做不改变安全语义的最小修复。

**Tech Stack:** Windows CMD、PowerShell 5.1+、Node.js/npm、Vitest 4、TypeScript 7、Tauri 2、Rust/Cargo、Cubism SDK for Web

## Global Constraints

- 只开发和验证 Windows，不增加其他操作系统的实现或 CI。
- npm 依赖缺失时自动执行 `npm install`。
- Cubism 缺失时，仅在 `CUBISM_SDK_ROOT` 已配置后自动执行 `npm run prepare:cubism`；否则明确失败。
- 只允许 `npm run tauri -- dev` 拥有 Vite 启动过程，不手工启动第二个 Vite。
- 不调用真实 provider，不读取或输出 API Key，不删除宠物或创建草稿。
- 不修改正式 `apps/desktop/public/creation-content`、Live2D 模型或 Task15 证据。
- 不修改或删除 `.worktrees/breath-sway-runtime`。
- 保持候选发布、认领和 motion profile 的 Windows 文件安全语义不变。
- 现有未跟踪文件 `docs/新对话开发交接摘要.md` 不加入任何实施提交。

import { readFileSync } from "node:fs";
import { describe, expect, it } from "vitest";

const cmd = readFileSync(
  new URL("../../../一键启动桌宠开发环境.cmd", import.meta.url),
  "utf8",
);
const powershell = readFileSync(
  new URL("../../../scripts/start-desktop-pet-dev.ps1", import.meta.url),

describe("Windows one-click development startup", () => {
  it("keeps the double-click wrapper path-independent and diagnosable", () => {

    expect(cmd).toContain("%~dp0scripts\\start-desktop-pet-dev.ps1");
    expect(cmd).toContain("-NoProfile -ExecutionPolicy Bypass");
    expect(cmd).toContain("%ERRORLEVEL%");
    expect(cmd).toMatch(/if not .*==.*0[\s\S]*pause/i);
    expect(cmd).toMatch(/exit \/b/i);
  });

  it("prepares dependencies and Cubism before the only Tauri dev start", () => {
    expect(powershell).toContain("$PSScriptRoot");
    expect(powershell).toContain("Get-Command npm.cmd");
    expect(powershell).toContain("Get-Command cargo.exe");
    expect(powershell).toContain("& $npmCommand ls --depth=0 --silent");
    expect(powershell).toContain("node_modules/.bin/tauri.cmd");
    expect(powershell).toContain("& $npmCommand install");
    expect(powershell).toContain("Core/live2dcubismcore.min.js");
    expect(powershell).toContain("Framework/src/live2dcubismframework.ts");
    expect(powershell).toContain("public/live2d/Core/live2dcubismcore.min.js");
    expect(powershell).toContain("$env:CUBISM_SDK_ROOT");
    expect(powershell).toContain("& $npmCommand run prepare:cubism");
    expect(powershell).toContain("exit 12");
    expect(powershell).toContain("exit 14");
    expect(powershell).toContain("& $npmCommand run tauri -- dev");

    const cubismGuard = powershell.indexOf("$env:CUBISM_SDK_ROOT");
    const prepare = powershell.indexOf("& $npmCommand run prepare:cubism");

    const incompleteSdkExit = powershell.indexOf("exit 14");
    const start = powershell.indexOf("& $npmCommand run tauri -- dev");
    expect(cubismGuard).toBeGreaterThan(-1);
    expect(missingSdkExit).toBeGreaterThan(cubismGuard);
    expect(prepare).toBeGreaterThan(cubismGuard);
    expect(incompleteSdkExit).toBeGreaterThan(prepare);
    expect(start).toBeGreaterThan(prepare);
    expect(start).toBeGreaterThan(incompleteSdkExit);

});

- [ ] **Step 4: Add the minimal PowerShell orchestrator**

Create `scripts/start-desktop-pet-dev.ps1`:

```powershell
$ErrorActionPreference = "Stop"

$repoRoot = Split-Path -Parent $PSScriptRoot
$desktopRoot = Join-Path $repoRoot "apps/desktop"
$tauriCommand = Join-Path $desktopRoot "node_modules/.bin/tauri.cmd"
$cubismCore = Join-Path $desktopRoot ".vendor/live2d-cubism-sdk/Core/live2dcubismcore.min.js"
$cubismFramework = Join-Path $desktopRoot ".vendor/live2d-cubism-sdk/Framework/src/live2dcubismframework.ts"
$publicCubismCore = Join-Path $desktopRoot "public/live2d/Core/live2dcubismcore.min.js"

$npm = Get-Command npm.cmd -ErrorAction SilentlyContinue
if (-not $npm) {
  Write-Error "未找到 npm。请先安装 Node.js（包含 npm），然后重新双击启动。"
  exit 10
}
$npmCommand = $npm.Source

$cargo = Get-Command cargo.exe -ErrorAction SilentlyContinue
if (-not $cargo) {
  Write-Error "未找到 cargo。请先安装 Rust 工具链，然后重新双击启动。"
  exit 11
}

function Test-CubismRuntime {
  return (Test-Path -LiteralPath $cubismCore -PathType Leaf) -and
    (Test-Path -LiteralPath $cubismFramework -PathType Leaf) -and
    (Test-Path -LiteralPath $publicCubismCore -PathType Leaf)
}

Push-Location $desktopRoot
try {
  & $npmCommand ls --depth=0 --silent
  if ($LASTEXITCODE -ne 0 -or -not (Test-Path -LiteralPath $tauriCommand -PathType Leaf)) {
    Write-Host "首次运行或依赖不完整，正在执行 npm install..."
    & $npmCommand install
    if ($LASTEXITCODE -ne 0) {
      $code = $LASTEXITCODE
      Write-Error "npm install 失败，退出代码：$code"
      exit $code
    }
    & $npmCommand ls --depth=0 --silent
    if ($LASTEXITCODE -ne 0 -or -not (Test-Path -LiteralPath $tauriCommand -PathType Leaf)) {
      Write-Error "npm install 完成后依赖树或本地 Tauri CLI 仍不完整。"
      exit 13
    }
  }

  if (-not (Test-CubismRuntime)) {
    if ([string]::IsNullOrWhiteSpace($env:CUBISM_SDK_ROOT)) {
      Write-Error "缺少 Cubism SDK。请把 CUBISM_SDK_ROOT 设置为官方 Cubism SDK for Web 根目录。"
      exit 12
    }
    Write-Host "正在从 CUBISM_SDK_ROOT 准备 Cubism SDK..."
    & $npmCommand run prepare:cubism
    if ($LASTEXITCODE -ne 0) {
      $code = $LASTEXITCODE
      Write-Error "Cubism SDK 准备失败，退出代码：$code"
      exit $code
    }
    if (-not (Test-CubismRuntime)) {
      Write-Error "Cubism SDK 准备命令完成，但运行文件仍不完整。"
      exit 14
    }
  }

  Write-Host "正在启动 PetBaby 前端、Rust 后端和桌宠窗口..."
  & $npmCommand run tauri -- dev
  exit $LASTEXITCODE
} finally {
  Pop-Location
}
```

### Task 2: Freeze the direct Windows-native source boundary

> **最终复审修订：** 边界契约使用 schema `2` 的 canonical `directWindowsPatterns` 正则模式，覆盖原标记以及 crate alias、分组 `std::os` 导入和灵活空白的 `extern "system"`。扫描前使用聚焦的 Rust 非代码 token 遮罩排除注释、字符串、字符和字节字符字面量；每个 Rust 文件只读取一次，并以扫描结果和 canonical allowlist 精确相等同时证明无新增与无过期允许项。下方初始测试代码块由本修订和仓库中的最终测试实现取代。

**Files:**
- Create: `apps/desktop/src/windows-native-boundary.test.ts`
- Create: `apps/desktop/src-tauri/windows-native-boundary.json`

**Interfaces:**
- Consumes: all `*.rs` files recursively below `apps/desktop/src-tauri/src`.
- Produces: schema version `2` JSON contract with `allowedRustFiles: string[]` and `directWindowsPatterns: string[]`; test failure when a new Rust file directly uses a listed Windows pattern.

- [ ] **Step 1: Write the failing boundary contract test**

Create `apps/desktop/src/windows-native-boundary.test.ts`:

```ts
import { readFileSync, readdirSync } from "node:fs";
import path from "node:path";
import { fileURLToPath } from "node:url";
import { describe, expect, it } from "vitest";

type BoundaryContract = {
  schemaVersion: number;
  allowedRustFiles: string[];
  directWindowsMarkers: string[];
};

const rustRoot = fileURLToPath(new URL("../src-tauri/src/", import.meta.url));
const contract = JSON.parse(readFileSync(
  new URL("../src-tauri/windows-native-boundary.json", import.meta.url),
  "utf8",
)) as BoundaryContract;

function rustFiles(directory: string): string[] {
  return readdirSync(directory, { withFileTypes: true }).flatMap((entry) => {
    const absolute = path.join(directory, entry.name);
    if (entry.isDirectory()) return rustFiles(absolute);
    return entry.isFile() && entry.name.endsWith(".rs") ? [absolute] : [];
  });
}

describe("Windows-native Rust boundary", () => {
  it("keeps the versioned allowlist canonical", () => {
    expect(contract.schemaVersion).toBe(1);
    expect(contract.allowedRustFiles).toEqual([...new Set(contract.allowedRustFiles)].sort());
    expect(contract.directWindowsMarkers).toEqual([...new Set(contract.directWindowsMarkers)].sort());
    expect(contract.directWindowsMarkers.length).toBeGreaterThan(0);
  });

  it("does not allow direct Windows APIs to spread to another Rust file", () => {
    const directUsers = rustFiles(rustRoot)
      .filter((file) => {
        const source = readFileSync(file, "utf8");
        return contract.directWindowsMarkers.some((marker) => source.includes(marker));
      })
      .map((file) => path.relative(rustRoot, file).replaceAll("\\", "/"))
      .sort();

    expect(directUsers).toEqual(contract.allowedRustFiles);
    for (const relative of contract.allowedRustFiles) {
      const source = readFileSync(path.join(rustRoot, relative), "utf8");
      expect(
        contract.directWindowsMarkers.some((marker) => source.includes(marker)),
        `${relative} must remain a real direct Windows API user`,
      ).toBe(true);
    }
  });
});
```
