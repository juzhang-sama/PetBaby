# 真实校准实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让“校准”真正调整当前宠物的呼吸幅度、眨眼间隔和点击反馈强度，并支持实时预览、保存、取消与重置。

**Architecture:** Rust 以每宠物 key 保存强类型 `PetCalibrationV1`；设置页通过跨窗口协议向宠物运行时发送临时预览，运行时把同一配置注入静态图、动画图和 Live2D。保存先持久化再转正预览，取消恢复已保存快照；原独立 `calibration.html` 演示页退出生产入口。

**Tech Stack:** Rust、serde、SQLite state store、Tauri 2 events、TypeScript、Canvas/Live2D、Vitest

## Global Constraints

- 校准对象始终是打开校准面板时的当前宠物；切换宠物后必须中止旧预览并重新读取。
- `breathAmplitudePercent` 范围 0–5、默认 2；`blinkIntervalScale` 范围 0.5–2、默认 1；`feedbackStrength` 范围 0–1、默认 0.6。
- 临时预览不得持久化；保存失败必须恢复保存前的运行时参数；取消/关闭必须恢复已保存值。
- 呼吸与眨眼只在可见且 scheduler 未暂停时推进；隐藏时不得积累补帧或消耗额外 CPU。
- Live2D 优先使用语义参数；无眼部参数、静态图和动画图使用 140ms 的轻微纵向闭合反馈，不伪造眼部素材。
- 点击反馈强度只缩放已有 shake/bounce/effect 强度，不改变行为判定与 cooldown。
- 校准不提供抠图像素修复；抠图复核属于独立安全流程。
- 不修改现有未提交的 Cargo manifest 和交接摘要。
- 除非步骤另有说明，Rust 命令从 `apps/desktop/src-tauri` 执行，npm 命令从 `apps/desktop` 执行。

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]

pub fn state_key(pet_id: &str) -> Result<String, String> {

- [ ] **Step 3: 实现 renderer 映射**

- static PNG：呼吸按 `1 + sin(phase)*amplitude` 在底部中心变换；blink 为最多 3% 的短时纵向收缩。
- animated image：把原 `LIFE_V1.breathScaleX/breathShiftY` 乘以 `breathAmplitudePercent/2`；blink 在最终 display canvas 底部中心应用同一闭合权重，不改 hit envelope。

- presentation：shake amplitude 4、bounce amplitude 8、effect opacity/intensity 均乘 feedbackStrength；0 表示无视觉/窗口反馈但行为仍执行。
