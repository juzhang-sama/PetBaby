# 宠物呼吸与整体微动实施计划

> **供智能代理执行：** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` 按任务逐项实施。Cubism 操作共享同一个二进制源文件，不拆分为并行任务。步骤使用复选框跟踪。

**目标：** 在保留睁眼、闭嘴稳定形象的前提下，为首只宠物完成呼吸、身体轻摆、上半身渐变式头部跟随和受限视线，并通过真实 Live2D 运行时预览完成阶段验收。

**架构：** Cubism 模型使用三层职责单一的嵌套弯曲变形器；TypeScript 新增纯逻辑 `MicroMotionController`，由 `Live2DRenderer` 将呼吸、轻摆、头部跟随和眼球目标混合后写入模型。眨眼和嘴部参数不进入首版 manifest，缺失局部能力按可选能力静默降级。

**技术栈：** Live2D Cubism Editor 5.3.03、Cubism SDK for Web 5-r.5、TypeScript 7、Vitest 4、Vite 8、PowerShell、SHA-256。

## 全局约束

- 永不覆盖 `pet-live2d-source-v6-mouth-approved.cmo3` 和 `pet-live2d-source-v7-blink.cmo3`。
- 动作源文件固定为 `D:\PetBabyAssets\first-pet\05-cubism-project\pet-live2d-source-v8-motion-base.cmo3`。
- 运行时导出目录固定为 `D:\PetBabyAssets\first-pet\06-runtime-export\pet-live2d-v1`。
- 眼睛默认开闭值为 `1`，嘴开闭固定为 `0`；首版 manifest 不声明 `eyeOpen` 和 `mouthOpen`。
- 眼球 X/Y 运行时限制为 `[-0.35, 0.35]`，出现白边时收缩为 `[-0.25, 0.25]`。
- 不新增眼睑、口腔、耳朵、尾巴或其他美术素材。
- 出现无法通过减小幅度消除的白边、透明洞、五官漂移或明显拉伸时，回到上一个已保存版本。
- Cubism 视觉检查由用户确认；代码修改执行 TDD，测试通过后再提交。

- [ ] **Step 3：实现控制器**

```ts
export interface MicroMotionFrame {
  breath: number;
  bodySway: number;
  angleX: number;
  angleY: number;
  lookX: number;
  lookY: number;
}

const TAU = Math.PI * 2;
const LOOK_LIMIT = 0.35;

function clamp(value: number, min: number, max: number): number {
  return Math.min(max, Math.max(min, value));
}

export class MicroMotionController {
  private elapsedMs = 0;
  private paused = false;
  private carried = false;
  private target = { x: 0, y: 0 };
  private look = { x: 0, y: 0 };
  private frame: MicroMotionFrame = {
    breath: 0.5,
    bodySway: 0,
    angleX: 0,
    angleY: 0,
    lookX: 0,
    lookY: 0,
  };

  setLookTarget(target: { x: number; y: number } | null): void {
    this.target = target
      ? { x: clamp(target.x, -LOOK_LIMIT, LOOK_LIMIT), y: clamp(target.y, -LOOK_LIMIT, LOOK_LIMIT) }
      : { x: 0, y: 0 };
  }

  setCarried(carried: boolean): void {
    this.carried = carried;
  }

  setPaused(paused: boolean): void {
    this.paused = paused;
  }

  update(deltaMs: number): MicroMotionFrame {
    if (this.paused) return this.frame;
    const delta = clamp(deltaMs, 0, 100);
    this.elapsedMs += delta;
    const smoothing = 1 - Math.exp(-delta / 120);
    this.look.x += (this.target.x - this.look.x) * smoothing;
    this.look.y += (this.target.y - this.look.y) * smoothing;

    const breathWave = 0.5 + 0.5 * Math.sin(TAU * this.elapsedMs / 4_000);
    const sway = this.carried ? 0 : clamp(
      4.5 * Math.sin(TAU * this.elapsedMs / 7_500)
        + 1.5 * Math.sin(TAU * this.elapsedMs / 11_300),
      -6,
      6,
    );
    const driftX = this.carried ? 0 : 0.8 * Math.sin(TAU * this.elapsedMs / 11_000);
    const driftY = this.carried ? 0 : 0.4 * Math.sin(TAU * this.elapsedMs / 7_000 + 0.7);

    this.frame = {
      breath: this.carried ? 0.5 + (breathWave - 0.5) * 0.25 : breathWave,
      bodySway: sway,
      angleX: clamp(driftX + this.look.x / LOOK_LIMIT * 2, -3, 3),
      angleY: clamp(driftY + this.look.y / LOOK_LIMIT * 1.2, -2, 2),
      lookX: this.look.x,
      lookY: this.look.y,
    };
    return this.frame;
  }
}
```
