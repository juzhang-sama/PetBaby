> **供智能代理执行：** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` 按任务逐项实施。Cubism 操作共享同一个二进制源文件，不拆分为并行任务。步骤使用复选框跟踪。

**目标：** 在保留睁眼、闭嘴稳定形象的前提下，为首只宠物完成胸部呼吸和整体轻摆，并通过真实 Live2D 运行时预览完成阶段验收。头部跟随、眼球跟随、眨眼和口型仅保留研发成果，不进入当前生产版本。

**架构：** Cubism 生产模型保留呼吸和整体轻摆两个有效变形参数；TypeScript 新增纯逻辑 `MicroMotionController`，由 `Live2DRenderer` 只把呼吸和轻摆写入模型。头部、眼球、眨眼和嘴部参数不进入首版 manifest，缺失微动参数按可选能力静默降级。

**技术栈：** Live2D Cubism Editor 5.3.03、Cubism SDK for Web 5-r.5、TypeScript 7、Vitest 4、Vite 8、PowerShell、SHA-256。

- [x] **Step 3：实现控制器**

```ts
export interface MicroMotionFrame {
  breath: number;
  bodySway: number;
}

const TAU = Math.PI * 2;

function clamp(value: number, min: number, max: number): number {
  return Math.min(max, Math.max(min, value));
}

export class MicroMotionController {
  private elapsedMs = 0;
  private paused = false;
  private carried = false;
  private frame: MicroMotionFrame = {
    breath: 0.5,
    bodySway: 0,
  };

  setCarried(carried: boolean): void {
    this.carried = carried;
  }

  setPaused(paused: boolean): void {
    this.paused = paused;
  }

  update(deltaMs: number): MicroMotionFrame {
    if (this.paused) return this.frame;
    const delta = clamp(deltaMs, 0, 100);
    this.elapsedMs += delta;

    const breathWave = 0.5 + 0.5 * Math.sin(TAU * this.elapsedMs / 4_000);
    const sway = this.carried ? 0 : clamp(
      4.5 * Math.sin(TAU * this.elapsedMs / 7_500)
        + 1.5 * Math.sin(TAU * this.elapsedMs / 11_300),
      -6,
      6,
    );
    this.frame = {
      breath: this.carried ? 0.5 + (breathWave - 0.5) * 0.25 : breathWave,
      bodySway: sway,
    };
    return this.frame;
  }
}
```
