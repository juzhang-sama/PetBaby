# 单一常驻窗口模式 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 移除公开双模式选择，只保留默认显示、可手动隐藏、独占全屏避让并在 Win+D 后非侵入式恢复的常驻模式。

**Architecture:** 保持现有 companion reducer/ACK 事务作为唯一生产路径，旧 desktop preference 读取时迁移。新增只读 Win32 可见性探针，复用 750ms fullscreen loop 驱动有界 reconcile；Shell cloak 只诊断和安全重申，不操作 Explorer。

**Tech Stack:** Rust、Tauri 2、windows-sys、TypeScript、Vitest、Win32 DWM。

## Global Constraints

- 默认显示；托盘手动隐藏优先级高于自动恢复。
- 同屏独占全屏隐藏，退出全屏后按 userVisible 恢复。
- 不发送 Explorer/Progman 私有消息，不重启 Explorer，不循环重建窗口。
- 旧 `desktop` preference 必须安全迁移，不得导致启动失败。
