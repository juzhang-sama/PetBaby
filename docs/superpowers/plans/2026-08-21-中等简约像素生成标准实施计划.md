# 中等简约像素生成标准 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将所有新 AI 宠物形象默认切换到 `pixel-style-v2-animation-ready` 的 160 逻辑网格、24 色、身份保护色标准，同时无损读取和恢复历史 `pixel-style-v1`。

**Architecture:** 保留 `route=pixel-v1` 和 `renderer=animated-image-v1`，用版本化 style pack 区分视觉标准。Rust 在 SQLite revision 上固定 style ID 并显式传给 Python；Python 根据 style pack 选择提示词、后处理和 audit 版本；Rust 对最终 PNG 和 audit 重新绑定验证；TypeScript 严格解析 v1/v2 profile 和 snapshot。所有双读能力通过后，才把新会话默认值切到 v2，并进行三只真实宠物和代表性动作回归。

**Tech Stack:** Python 3、Pillow 11.3.x、pytest、lk888 `gpt-image-2`、Rust 2021、Tauri 2、rusqlite、image、serde、TypeScript 7、Vitest 4、Vite 8、Windows PowerShell/Git Bash。

## Global Constraints

- 新默认 style ID 固定为 `pixel-style-v2-animation-ready`；历史 ID 为 `pixel-style-v1`。
- `route` 继续为 `pixel-v1`，`profileKind` 继续为 `pixel-v1`，`renderer` 继续为 `animated-image-v1`。
- v2 输出继续为 `1024x1024 RGBA PNG`；逻辑网格固定为 160，主体可见颜色最多 24。
- v2 后处理固定 `BOX -> Image.Quantize.MAXCOVERAGE -> dither NONE -> NEAREST`，Pillow 依赖锁定 `>=11.3,<11.4`。
- v2 最多保护 4 个强调色；候选面积 0.05% 至 5%，与主色最小 CIEDE2000 色差至少 18，量化后匹配色差至多 12。
- v1 资产、提示词、哈希、audit v1、任务和已安装宠物不得重写或重新量化。
- Live2D 保持冻结；不删除历史代码，也不让它重新进入新生成路径。
- 新生成请求只传用户照片，不把 `认可参考图.png` 作为模型图片输入。
- 真实 provider 调用只在所有自动化测试通过后执行，沿用现有最多 3 次远程尝试和失败映射。
- 当前目录没有 `.git`，所有 `git commit` 步骤均不可执行；每个任务用“变更清单 + 测试输出”作为检查点，不初始化仓库、不伪造提交。

- [ ] **Step 3: 实现只处理可见像素的确定性量化**

`pixel_palette.py` 固定以下数据结构和算法顺序：

```python
@dataclass(frozen=True, slots=True)
class PixelPaletteReportV2:
    visible_color_count: int
    protected_accent_count: int


def quantize_animation_ready_rgba(
    image: Image.Image,
    profile: PixelPostprocessProfile,
) -> tuple[Image.Image, PixelPaletteReportV2]:
    rgba = image.convert("RGBA")
    visible = [(index, pixel[:3]) for index, pixel in enumerate(rgba.getdata()) if pixel[3] > 0]
    if not visible:
        raise ContractError("pixel artifact has no visible pixels")
    candidate_labels, candidate_rgb, shares = _quantize_visible(visible, colors=64)
    main = {index for index, share in enumerate(shares) if share >= 0.05}
    candidates = [
        index for index, share in enumerate(shares)
        if 0.0005 <= share < 0.05
        and main
        and min(delta_e_rgb(candidate_rgb[index], candidate_rgb[m]) for m in main) >= 18.0
    ]
    candidates.sort(
        key=lambda index: (
            -min(delta_e_rgb(candidate_rgb[index], candidate_rgb[m]) for m in main)
            * math.sqrt(shares[index]),
            candidate_rgb[index],
        )
    )
    protected = tuple(candidates[: profile.protected_accent_slots])
    # 非保护像素使用 MAXCOVERAGE 量化到 24-len(protected) 色；
    # 保护 cluster 的原位置强制写回 candidate_rgb；透明像素写 (0,0,0,0)。
    # 最后计算实际可见色数并拒绝 >24 或保护色匹配 DeltaE >12。
```

`_quantize_visible` 必须把可见 RGB 组成紧凑的 RGB strip，再调用：

```python
strip.quantize(
    colors=colors,
    method=Image.Quantize.MAXCOVERAGE,
    dither=Image.Dither.NONE,
)
```

`验证中等简约动作就绪.py` 使用每只 v2 母版对应的 JSON 标注文件；脚本在文件缺失、坐标超出 0..159、矩形反向或尾巴 enabled 但缺少 root/mask 时直接退出 2。用以下 Python 类型定义标注结构，矩形均为 `[left, top, right, bottom]`，点均为 `[x, y]`：

```python
Rect = tuple[int, int, int, int]
Point = tuple[int, int]


class TailAnnotation(TypedDict):
    enabled: bool
    root: Point | None
    mask: list[Point]
    disabledReason: str | None


class MotionAnnotation(TypedDict):
    logicalGridSize: Literal[160]
    eyes: dict[Literal["left", "right"], Rect]
    breathZone: Rect
    groundAnchors: list[Rect]
    tail: TailAnnotation
```

生成验收脚本先为每只宠物输出带坐标刻度的放大 160 网格图；执行者查看该图，为每只宠物创建 `annotations/<pet-id>.json`，写入肉眼确认的实际整数坐标，并把最终标注随产物保存。`scripts/像素动作库.py` 将 `LOGICAL=512`、`EYES`、`Y_ANCHOR` 和尾巴常量改为函数参数，从标注文件构造动作；不得再读取单猫固定坐标。动作脚本只做整数像素覆盖重绘：眨眼、呼吸；尾巴清晰且标注可靠时才做摇尾巴。循环首尾帧相同，ground anchor 变化为 0，所有帧最多 24 色并使用统一 160->1024 映射。
