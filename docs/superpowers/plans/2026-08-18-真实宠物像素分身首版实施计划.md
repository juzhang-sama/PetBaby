> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans in fast batch mode. Implement Task 1 through Task 6 continuously with checkbox (`- [ ]`) tracking, defer test execution and review gates to Task 7, and do not insert per-task subagent review pauses.

**Goal:** 在保留现有照片上传、身份来源、任务恢复、重试、预览确认、安装和清理能力的基础上，用 lk888 `gpt-image-2` 生成完整像素宠物单图，并通过 `animated-image-v1` 固定动作完成一个真实照片样本的端到端闭环。

**Architecture:** 桌面端继续是 session、revision、attempt、恢复和终态清理的唯一编排真相；受控后端把身份分析与 AI 补全合并为一个桌面可见步骤，再用固定像素风格包和全部照片生成一张完整透明 PNG。Rust 独立复验审计与 PNG、编译 schema v3 `animated-image-v1` 候选包；TypeScript 单图 renderer 扩展固定整图动作，设置页完成真实运行检查后才允许用户接受安装。旧 Live2D 照片分身链路保留代码和历史数据，但不再处理新 revision。

export interface PixelIdentityTraitV1 {
  key: PixelIdentityTraitKey;
  value: string;
  source: "user" | "ai-completed";
  evidencePhotoIds: string[];
}

export interface PixelAppearanceProfileV1 {
  schemaVersion: 1;
  species: "cat";
  styleProfileId: "pixel-style-v1";
  traits: PixelIdentityTraitV1[];
  completionSummary: PixelIdentityTraitKey[];

export interface PixelPhotoAvatarSnapshot {
  route: "pixel-v1";
  sessionId: string;
  revision: number;
  step: PixelPhotoAvatarStep;
  providerJobId: string | null;
  profile: PixelAppearanceProfileV1 | null;
  attempts: Partial<Record<"analyzeIdentity" | "generatePixelAvatar", number>>;
  errorCode: PhotoAvatarErrorCode | null;
  errorMessage: string | null;
}

export function parsePixelPhotoAvatarSnapshot(input: unknown): PixelPhotoAvatarSnapshot {
  const value = exactObject(input, "pixelPhotoAvatarSnapshot", [
    "route", "sessionId", "revision", "step", "providerJobId", "profile",
    "attempts", "errorCode", "errorMessage",
  ]);
  if (value.route !== "pixel-v1") fail("route must be pixel-v1");
  if (typeof value.sessionId !== "string" || value.sessionId.length === 0) fail("sessionId is invalid");
  if (!Number.isInteger(value.revision) || Number(value.revision) < 0) fail("revision is invalid");
  if (typeof value.step !== "string" || !PIXEL_PHOTO_AVATAR_STEPS.includes(value.step as PixelPhotoAvatarStep)) fail("step is invalid");
  const attempts = parsePixelAttempts(value.attempts);
  return {
    route: "pixel-v1",
    sessionId: value.sessionId,
    revision: Number(value.revision),
    step: value.step as PixelPhotoAvatarStep,
    providerJobId: value.providerJobId === null ? null : nonEmptyString(value.providerJobId, "providerJobId"),
    profile: value.profile === null ? null : parsePixelAppearanceProfileV1(value.profile),
    attempts,
    errorCode: value.errorCode === null ? null : parsePhotoAvatarErrorCode(value.errorCode),
    errorMessage: value.errorMessage === null ? null : nonEmptyString(value.errorMessage, "errorMessage"),
  };
}

- [ ] **Step 5: 写 Python wire 测试合同并实现**

保留当前 `StepRequest` 供旧链路编译，并行增加 `PixelStepRequest`；公共入口根据 `step` 选择唯一 parser，不能让同一 payload 同时通过两种合同：

```python
_PIXEL_STEPS = frozenset({"analyzeIdentity", "generatePixelAvatar"})
PIXEL_IDENTITY_TRAIT_KEYS = (
    "faceShape", "faceProportions", "eyeShape", "eyeColor", "earShape",
    "primaryFurColor", "secondaryFurColor", "faceMarkings", "chestMarkings",
    "pawMarkings", "bodyMarkings", "tailShape", "tailMarkings",
    "signatureMarks", "temperament",
)
_STEP_FIELDS = frozenset({
    "sessionId", "revision", "providerSessionId", "step", "attempt",
    "consentVersion", "sourceImages", "profile", "styleProfileId",
    "styleProfileSha256", "modification", "lockedTraits",
})

@dataclass(frozen=True)
class PixelStepRequest:
    session_id: str
    revision: int
    provider_session_id: str | None
    step: str
    attempt: int
    consent_version: str
    source_images: tuple[SourceImage, ...]
    profile: dict[str, Any] | None
    style_profile_id: str
    style_profile_sha256: str
    modification: str | None
    locked_traits: tuple[str, ...]

def parse_step_request(payload: Mapping[str, Any]) -> StepRequest | PixelStepRequest:
    step = _require_string(payload, "step")
    if step == "generatePixelAvatar":
        return PixelStepRequest.parse(payload)
    if step == "analyzeIdentity":
        return PixelStepRequest.parse(payload) if "styleProfileId" in payload else StepRequest.parse(payload)
    return StepRequest.parse(payload)
```

}

};
```

同一步修改 Python HTTP 边界：`create_app.submit` 直接调用 `PixelStepRequest.parse(payload)`，`PipelineRunner` 的活动入口只接受 `PixelStepRequest`。保留 `StepRequest` 类和旧 pipeline 函数供历史单元回归，但任何新的 `completeAppearance`/`renderTextureAtlas` HTTP 请求固定返回 `invalidInput`。测试必须证明切换前 Task 3 双路由绿色，切换后像素请求绿色且旧 HTTP 新建请求关闭。

if ($evidence.providerTaskId -notmatch '^[0-9]+$') { throw 'providerTaskId must be numeric' }
if ($evidence.styleProfileId -ne 'pixel-style-v1') { throw 'style profile is invalid' }
if ($evidence.runtimeRenderer -ne 'animated-image-v1' -or $evidence.runtimeSchemaVersion -ne 3) { throw 'runtime contract is invalid' }
if (@($evidence.motionResults).Count -ne 7) { throw 'exactly seven motion results are required' }
if ($null -eq $evidence.identityReview -or $null -eq $evidence.visualReview) { throw 'manual reviews are required' }
if ($evidence.cleanup.local -notin @('deleted', 'pending')) { throw 'local cleanup state is invalid' }
if ($evidence.cleanup.backend -notin @('deleted', 'pending')) { throw 'backend cleanup state is invalid' }
if ($evidence.cleanup.upstream -ne 'unsupported') { throw 'upstream cleanup must be unsupported' }
```

无论 PASS 或 FAILED，都停止在样本 01；不自动开始样本 02、20 样本矩阵、边缘藏身、声音或完整角色帧动画。
