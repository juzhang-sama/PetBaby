# 照片分身失败状态与图片接收修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复照片分身旧失败状态残留、取消竞态、GPT-image-2.0 PNG 接收失败及错误重试导致的重复付费生成。

**Architecture:** 创建视图负责把照片运行取消与创建草稿放弃组成一次完整操作，并在恢复终态草稿时创建新会话。Rust 存储层以条件更新保护取消终态，Python 在严格审计前确定性标准化 provider PNG，并把本地合同错误映射为非重试错误。各层保留安全错误码与用户消息，不传递敏感 provider 数据。

**Tech Stack:** TypeScript 7、Vitest、Tauri 2、Rust、rusqlite、Python 3.12、pytest、Pillow。

## Global Constraints

- 不触发新的 LK888 生成请求；Python 验证只使用合成 PNG 或现有历史图片。
- 不删除机械审计门；只在审计前做确定性背景、缩放和 alpha 标准化。
- 只有网络、超时、provider 5xx 和明确临时不可用允许自动重试。
- 不改其他创建路线、视觉提示词、Live2D 或标准猫功能。
- 保留工作树内既有未提交修改，不撤销或覆盖无关成果。
