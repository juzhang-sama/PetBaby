# 停用眨眼效果 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从当前生产版本删除自动眨眼调度、整图压缩和设置控件，同时保持校准数据向后兼容。

**Architecture:** `PetStage` 不再拥有眨眼时钟，`PetRenderer` 不再暴露 `setBlink`。三类 renderer 只保留呼吸和既有微动；校准 schema 暂时保留休眠字段以读取旧数据。

**Tech Stack:** TypeScript、Vitest、Canvas 2D、Live2D runtime、Vite。

## Global Constraints

- 不制作或驱动眼睑、闭眼贴图、嘴部或转头能力。
- 不迁移或删除既有 `blinkIntervalScale` 持久化字段。
- 任何生产代码修改前必须取得对应 RED。
