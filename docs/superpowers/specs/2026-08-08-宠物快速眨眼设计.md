# 宠物快速眨眼设计

**目标：** 在不新增闭眼美术素材的前提下，为当前正面坐姿宠物建立第一版自然可用的左右眼眨眼，并保留后续替换为精细闭眼素材的空间。

**基准文件：** `D:\PetBabyAssets\first-pet\05-cubism-project\pet-live2d-source-v6-mouth-approved.cmo3`

**输出文件：** `D:\PetBabyAssets\first-pet\05-cubism-project\pet-live2d-source-v7-blink.cmo3`

## 范围

- 使用现有眼球、虹膜瞳孔和眼周结构，通过局部纵向压缩模拟闭眼。
- 左右眼分别绑定标准参数 `ParamEyeLOpen` 与 `ParamEyeROpen`。
- 每只眼保留 `0`（闭眼）、`0.5`（半闭）、`1`（睁眼）三个状态。
- 运行时可同步驱动左右参数形成普通眨眼，也保留独立驱动能力。
- 本阶段不新增闭眼图片、不重绘眼睑、不制作眨眼 Motion，也不修复眼球 X/Y 极限位置出现的边缘空隙。

## 结构

每只眼建立一个仅包裹该眼相关对象的眨眼变形器。变形器包含该眼的眼球和虹膜瞳孔，不包含鼻子、嘴部、另一只眼或大面积脸部毛发。眨眼变形器作为该眼现有眼球/虹膜对象及其 X/Y 变形器的外层父级，同时保持在脸部全局变形器之内；已有眼球 X/Y 关键形和参数保持不变。

闭眼采用以眼睛视觉中心为基准的纵向收拢：上半部向下、下半部向上，水平宽度尽量保持不变。虹膜随眼球共同压缩，避免闭眼时仍残留完整圆形瞳孔。闭眼状态允许保留一条很窄的暗色眼缝，但不得形成明显圆眼、透明洞或大块白色月牙。

## 参数行为

- `1`：保持 v6 当前睁眼外观，不改变宠物身份特征。
- `0.5`：可见眼高为睁眼状态的 `45%–55%`，轮廓连续，用于眨眼过渡。
- `0`：可见眼高为睁眼状态的 `8%–15%`，形成窄缝；水平宽度相对睁眼状态变化不超过 `5%`，眼周毛发不发生明显塌陷。

左右眼先分别制作和验证，再同时置于相同数值检查同步眨眼。参数恢复值为 `1`；眼球 X/Y 的恢复值为 `0`；嘴开闭的恢复值为 `0`。

## 安全与回退

- 开始编辑前从 v6 另存为 v7，禁止覆盖 v6。
- 只修改眼部相关对象和眨眼参数，不修改已验收的嘴部关键形。
- 若局部压缩暴露透明洞、旧眼睛重影或大面积白边，先缩小闭眼幅度；仍无法接受时停止方案 1，保留 v7 试验文件并转入闭眼覆盖层方案。
- 每完成一只眼就保存一次；最终保存后记录 v7 的 SHA-256。

## 验收

1. 左眼从 `1 → 0.5 → 0 → 1` 往返时，眼睛连续闭合并恢复。
2. 右眼执行相同检查，左右幅度和闭合方向一致。
3. 两眼同步往返三次，不出现透明洞、圆形瞳孔残留、明显白边、脸部整体位移或纹理翻转。
4. 分别在眼球 X/Y 为 `0` 和 `±0.5` 时组合眨眼，闭合与恢复均可工作；`±1` 极限偏移的既有白边不属于本阶段范围。
5. 分别检查嘴开闭 `0` 与 `1`，眨眼不得改变鼻子、嘴线或嘴部幅度。
6. 用户确认第一版眨眼自然度可接受后，将 v7 作为下一阶段输入。

## 后续升级

如需要更高的近距离表现，可在不改变 `ParamEyeLOpen`、`ParamEyeROpen` 接口的情况下，增加闭眼毛发覆盖层和闭眼线，并逐步替换当前压缩形变。运行时代码无需因此更换参数名或眨眼调度逻辑。
