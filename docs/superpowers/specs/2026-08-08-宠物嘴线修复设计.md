# 宠物嘴线修复设计

## 1. 问题与目标

当前 `mouth_line` 图层被切成尖端朝下的 `V` 形毛发块，并包含过多口鼻周围的白毛。该图层上下移动时，白毛与下巴纹理会随嘴线整体位移，导致嘴部动作不自然。

本次修复将嘴线重建为 `∧` 形：尖点位于鼻子下方，左右两支向左下、右下展开。修复只服务于第一版正面坐姿宠物的中性嘴型和嘴巴开合，不扩展到牙齿、舌头、咀嚼或复杂说话口型。

## 2. 资产边界

- `pet-live2d-source-v4.cmo3` 保持不变，继续作为眼部阶段的回退版本。
- `pet-live2d-source-v5-mouth.cmo3` 是嘴部工作的 Cubism 副本。
- 不覆盖现有 `mouth_line.png`，候选资产使用版本化文件名 `mouth_line-v2.png`。
- 不修改已经验收的眼睛、虹膜、眼球参数，也不改变鼻子、脸型、耳朵、前腿和尾巴。
- 在候选通过视觉验收前，不写回正式 KRA、PSD 或 CMO3。

## 3. 嘴部结构

嘴部拆成三个职责明确的部分：

1. `nose`：保持现状，作为固定的口鼻定位基准。
2. `mouth_line-v2`：只包含形成 `∧` 形所需的暗色嘴线及紧邻的少量过渡纹理，不携带大块白毛。
3. `mouth_backfill-v1`：位于嘴线下方，用于嘴巴张开时遮挡原始闭口纹理，避免露空、重影或背景穿帮。

嘴线不是把现有 `V` 图块垂直翻转，而是参考主立绘的颜色、柔边和轻微不对称，重新绘制小范围纹理。这样可以保留宠物辨识度，同时避免倒置毛流。

## 4. 实施流程

1. 从主立绘裁取口鼻局部作为不可修改的视觉基准。
2. 制作独立的 `mouth_line-v2` 与 `mouth_backfill-v1` 候选。
3. 生成原图、静态合成、轻微张嘴三个局部对照画面。
4. 由用户确认嘴线方向、粗细、位置和宠物相似度。
5. 将通过验收的候选写入分层 KRA/PSD，并另存新的源文件版本。
6. 在 `pet-live2d-source-v5-mouth.cmo3` 中更新嘴部图层，创建嘴巴开合参数的关键形。
7. 验证中性、轻微张嘴和最大张嘴状态，再另存下一版 CMO3。

## 5. Cubism 绑定原则

- 使用标准嘴巴开合参数 `ParamMouthOpenY`，取值范围 `0` 到 `1`。
- `0` 为中性闭口，必须与通过验收的静态合成一致。
- `0.5` 为轻微张嘴，只产生局部形变。
- `1` 为第一版允许的最大张嘴幅度，仍不得牵动大面积面部白毛。
- 鼻子原则上保持固定；如果极限状态出现断缝，只允许做像素级补偿，不把鼻子纳入主要开合运动。
- 第一轮不绑定 `ParamMouthForm`，避免同时引入口型和情绪两个变量，确认开合稳定后再单独设计。

## 6. 验收标准

- 中性状态的嘴线明确呈 `∧` 形，尖点贴近鼻子下方。
- 左右嘴线允许符合原始形象的轻微不对称，但不得出现机械直线或通用卡通猫嘴感。
- 中性静态合成与主立绘在口鼻区域不存在明显跳变、重影或色块边界。
- 参数从 `0` 移动到 `1` 时，运动集中在嘴线和紧邻区域，周围白毛、鼻子和脸颊不发生明显整体位移。
- 张嘴时不露透明洞、不显示重复的旧嘴线，也不产生倒置毛流。
- 已验收的眼睛开闭和眼球 X/Y 行为保持不变。

## 7. 回退策略

任何候选不通过时，只丢弃对应的版本化候选文件。KRA、PSD 和 CMO3 均采用另存新版本的方式推进，不删除或覆盖 `v4` 及更早的工程文件。
