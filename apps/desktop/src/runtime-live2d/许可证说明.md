# Cubism 许可证说明

## 项目自有适配代码

`probe.ts`、`cubism-adapter.ts` 及探针集成属于本项目代码，不包含 Cubism SDK 或模型资产。

## 官方 Cubism Framework/Core

Cubism Framework/Core 是 Live2D 官方软件开发套件，使用前必须从官方渠道取得并遵守其许可证。仓库不提交、不重新分发 Core、Framework 或官方示例模型。

## 测试模型与产品模型

测试模型仅用于获得明确授权的技术验证；产品模型必须由用户或公司确认版权、商用范围和再分发许可。

未审查的资产不能进入安装包；本文件不构成对用户或公司实际授权范围的结论。
